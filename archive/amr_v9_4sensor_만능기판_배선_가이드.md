## 목적과 범위

이 문서는 ESP32 #1 AMR v9에 코딩된 다음 네 센서를 만능기판으로 연결해
반복 시험과 영상 촬영에 사용할 수 있는 프로토타입을 제작하기 위한
작업용 가이드다.

- MQ-135 가스 센서
- KY-026 화염 센서
- Adafruit VL53L1X ToF 거리 센서
- MQ-2 가스·연기 센서

설계 목표는 완벽한 양산 기판이 아니라 다음 조건을 만족하는 촬영용
프로토타입이다.

- 점퍼선보다 진동에 강하다.
- 센서 한 개가 고장 나도 해당 센서와 케이블만 교체할 수 있다.
- 두 MQ 센서의 5V 전원과 ESP32 3.3V 신호를 안전하게 분리한다.
- 납땜 후 핀과 전압을 단계적으로 검증할 수 있다.

이 문서에는 모터 드라이버, 모터 전원, ESP32 #2 ARM, 서보, 그리퍼,
Raspberry Pi 대시보드 및 LiPo 전압 측정 회로를 포함하지 않는다.

## 이전 만능기판 설계에서 계승하는 원칙

기존
`docs/superpowers/specs/2026-07-28-amr-perfboard-wiring-design.md`의 핵심
원칙을 이번 네 센서 범위에 맞게 적용한다.

1. 메인 전원·인터페이스 기판과 센서 분배 기판의 **2장 구조**를 사용한다.
2. 센서를 만능기판에 직접 납땜하지 않고 JST-XH 계열 잠금형 커넥터로
   연결한다.
3. 각 센서를 다른 센서와 독립적으로 분리·교체할 수 있게 한다.
4. I2C와 아날로그 센서선을 모터 전원선 및 USB 케이블에서 떨어뜨린다.
5. MQ 센서는 발열과 공기 흐름을 고려해 차체 상단에 고정한다.
6. 모든 케이블에 센서명, 핀 1 표시 및 스트레인 릴리프를 적용한다.

이전 가이드에 포함됐던 TCS34725, MLX90614, FC-37 및 라인트레이싱
센서는 이번 제작에서 제외한다. 일정이 급한 현재 단계에는 v9에 이미
코딩된 네 센서만 완성한다.

## 먼저 확인할 핵심 경고

1. 납땜하거나 커넥터를 꽂고 뺄 때는 USB와 외부 5V 전원을 모두 끈다.
2. MQ-135와 MQ-2의 `AO`를 ESP32 ADC에 직접 연결하지 않는다.
3. 두 MQ 센서의 AO에는 각각 `10kΩ/15kΩ` 분압 회로를 사용한다.
4. MQ-135와 MQ-2 히터를 ESP32 `3V3` 핀에서 공급하지 않는다.
5. ESP32, 두 기판, 네 센서 및 외부 5V 전원의 GND를 공통으로 연결한다.
6. 외부 5V `+`와 USB 5V를 전원 경로 확인 없이 서로 직결하지 않는다.
7. JST-XH 하우징을 제작할 때 앞면과 뒷면을 혼동해 핀 순서를 좌우 반전하지
   않는다.
8. 전원 투입 전 멀티미터로 단락과 모든 커넥터의 핀 연결을 검사한다.
9. GPIO34와 GPIO33의 ADC 노드에서 3.3V가 넘으면 즉시 전원을 끈다.

## 확정 구조: 만능기판 2장

### 기판 A: 메인 전원·인터페이스 기판

ESP32 가까이에 설치하며 다음 기능을 담당한다.

- 외부 5V 센서 전원 입력
- ESP32 3.3V 분배
- 공통 GND 분배
- MQ-135 AO 10kΩ/15kΩ 분압
- MQ-2 AO 10kΩ/15kΩ 분압
- KY-026 디지털 입력 연결
- VL53L1X SDA/SCL 연결
- 센서별 기판 간 커넥터
- 전압 및 신호 측정용 테스트 포인트

### 기판 B: 센서 분배 기판

차체 센서 쪽에 설치하며 다음 기능을 담당한다.

- 기판 A에서 온 네 개의 독립 케이블 수용
- 센서별 JST-XH 잠금형 커넥터 제공
- 센서 위치로 가는 케이블 집선
- 센서 한 개만 독립적으로 분리·교체
- 케이블 스트레인 릴리프

센서 모듈 자체는 기판 B에 납땜하지 않는다. 센서 모듈과 기판 B 사이에도
분리 가능한 케이블을 사용한다.

```text
외부 5V 센서 전원
        │
        v
┌──────────────────────┐    센서별 독립 케이블    ┌──────────────────┐
│ 기판 A               │ ───────────────────────> │ 기판 B           │
│ 전원·인터페이스      │                          │ 센서 분배         │
│ 분압·ESP32 연결      │ <─────────────────────── │ 교체형 커넥터     │
└──────────────────────┘       신호 반환           └────────┬─────────┘
                                                           │
                         MQ-135 / KY-026 / VL53L1X / MQ-2
```

## 준비물

| 항목 | 권장 수량 | 용도 |
|---|---:|---|
| 적당한 크기의 만능기판 | 2 | 기판 A와 기판 B |
| ESP32 개발 보드 | 1 | ESP32 #1 AMR |
| MQ-135, KY-026, VL53L1X, MQ-2 | 각 1 | 네 센서 |
| JST-XH 3핀 세트 | 최소 6쌍 | MQ-135, KY-026, MQ-2 경로 |
| JST-XH 4핀 세트 | 최소 2쌍 | VL53L1X 경로 |
| 10kΩ 저항 | 2 | 두 MQ 분압의 상단 저항 |
| 15kΩ 저항 | 2 | 두 MQ 분압의 하단 저항 |
| 핀헤더 또는 소켓헤더 | 필요량 | ESP32와 점검 가능한 연결 |
| 연선 케이블 | 필요량 | 기판 간·센서 연결 |
| 안정적인 정전압 5V 전원 | 1 | 두 MQ 센서 전원 |
| 열수축튜브, 케이블타이 | 필요량 | 절연과 스트레인 릴리프 |
| 라벨 또는 수축튜브 마커 | 필요량 | 센서명과 핀 1 표시 |
| 멀티미터 | 1 | 단락·도통·전압 검사 |

3핀 세트의 실제 수량은 기판 A↔B 케이블과 기판 B↔센서 케이블을 각각
분리형으로 만들지에 따라 늘어난다. 센서 교체 편의성을 우선하면 모든
구간을 커넥터로 분리한다.

5V 레일 안정화를 위해 기판 A의 센서 전원 입력 근처에 극성을 지켜
전해 커패시터를 배치할 자리를 남겨 두는 것을 권장한다. 부품값을 임의로
확정하기보다 실제 전원 모듈의 권장 회로를 따른다.

## 전원 구조

### 촬영용 프로토타입의 권장 분리

ESP32를 PC USB에 연결해 업로드와 Serial 통신을 수행하는 동안에는 다음
구성이 가장 이해하기 쉽다.

```text
PC USB ────────────── ESP32 USB
                         │
ESP32 3V3 ────────── 기판 A 3V3 버스
ESP32 GND ──────┬──── 기판 A/B 공통 GND 버스
                │
외부 5V GND ────┘
외부 5V + ─────────── 기판 A 5V_SENSOR 버스
```

- `5V_SENSOR`는 MQ-135와 MQ-2에만 공급한다.
- `3V3`는 KY-026과 VL53L1X에 공급한다.
- 외부 5V의 `+`는 USB가 연결된 ESP32의 5V 핀과 직접 연결하지 않는다.
- 신호의 기준 전압을 맞추기 위해 GND만 공통으로 연결한다.
- 향후 하나의 5V 전원으로 ESP32까지 공급하려면 USB 역급전 방지와 보드의
  5V/VIN 구조를 별도로 확정한 뒤 변경한다.

두 MQ 센서의 히터 전류 때문에 전원 여유가 부족하면 ESP32 재부팅, USB
끊김 또는 ADC 흔들림이 나타날 수 있다. 두 센서를 동시에 연결한 상태에서
5V_SENSOR 전압이 유지되는지 실제로 측정한다.

## 커넥터 명칭과 핀 배열

아래 이름은 기판 B에서 센서로 나가는 최종 커넥터에 사용한다. 기판 A와
기판 B 사이의 대응 커넥터에도 같은 센서명과 핀 번호를 표시한다.

### `J_MQ135` — 3핀

| 핀 | 신호 | 권장 색상 |
|---:|---|---|
| 1 | 5V_SENSOR | 빨강 |
| 2 | GND | 검정 |
| 3 | MQ135_AO_RAW | 노랑 |

센서 모듈의 DO에는 접점을 만들지 않는다.

### `J_FLAME` — 3핀

| 핀 | 신호 | 권장 색상 |
|---:|---|---|
| 1 | 3V3 | 주황 또는 빨강 |
| 2 | GND | 검정 |
| 3 | FLAME_DO | 노랑 |

센서 모듈의 AO에는 접점을 만들지 않는다.

### `J_TOF` — 4핀

| 핀 | 신호 | 권장 색상 |
|---:|---|---|
| 1 | 3V3 | 주황 또는 빨강 |
| 2 | GND | 검정 |
| 3 | I2C_SDA | 파랑 |
| 4 | I2C_SCL | 초록 |

VL53L1X의 GPIO와 XSHUT에는 접점을 만들지 않는다. I2C 주소는 `0x29`다.

### `J_MQ2` — 3핀

| 핀 | 신호 | 권장 색상 |
|---:|---|---|
| 1 | 5V_SENSOR | 빨강 |
| 2 | GND | 검정 |
| 3 | MQ2_AO_RAW | 흰색 또는 노랑 |

센서 모듈의 DO에는 접점을 만들지 않는다.

### 커넥터 좌우 반전 방지

1. 기판 실장면에서 보이는 핀 1에 삼각형 또는 흰 점을 표시한다.
2. 케이블 양쪽 하우징에도 핀 1을 표시한다.
3. 커넥터를 꽂은 상태에서 핀 1의 선 색이 양 끝 모두 같은지 확인한다.
4. 납땜면에서 볼 때 좌우가 반전된다는 점을 기억한다.
5. 전원 투입 전 센서 VCC 핀에서 기판 A의 해당 전원 테스트 포인트까지
   도통을 확인한다.

## 기판 A 전체 네트리스트

| 기판 A 입력 또는 커넥터 | 중간 회로 | ESP32/전원 연결 |
|---|---|---|
| 5V_SENSOR_IN + | 5V_SENSOR 버스 | J_MQ135-1, J_MQ2-1 |
| 5V_SENSOR_IN GND | GND 버스 | ESP32 GND와 모든 J-2 |
| ESP32 3V3 | 3V3 버스 | J_FLAME-1, J_TOF-1 |
| J_MQ135-3 | 10kΩ 후 ADC 노드, 노드에서 15kΩ으로 GND | GPIO34 |
| J_FLAME-3 | 직접 디지털 신호 | GPIO27 |
| J_TOF-3 | I2C SDA | GPIO21 |
| J_TOF-4 | I2C SCL | GPIO22 |
| J_MQ2-3 | 10kΩ 후 ADC 노드, 노드에서 15kΩ으로 GND | GPIO33 |

두 분압 회로:

```text
J_MQ135-3 ── 10kΩ ──┬── TP_MQ135_ADC ── GPIO34
                     │
                    15kΩ
                     │
GND ─────────────────┘
```

```text
J_MQ2-3 ── 10kΩ ──┬── TP_MQ2_ADC ── GPIO33
                   │
                  15kΩ
                   │
GND ───────────────┘
```

분압 저항은 GPIO34와 GPIO33 가까이에 배치한다. 센서의 `AO_RAW` 선은
5V 범위일 수 있으므로 ADC 노드와 혼동하지 않게 실크펜 또는 라벨로
구분한다.

## 기판 B 전체 네트리스트

기판 B는 신호를 처리하지 않고 센서별 선을 그대로 전달한다.

| 기판 A에서 온 신호 | 기판 B 센서 커넥터 |
|---|---|
| MQ135 5V_SENSOR/GND/AO_RAW | J_MQ135 1/2/3 |
| FLAME 3V3/GND/DO | J_FLAME 1/2/3 |
| TOF 3V3/GND/SDA/SCL | J_TOF 1/2/3/4 |
| MQ2 5V_SENSOR/GND/AO_RAW | J_MQ2 1/2/3 |

기판 B에는 두 MQ용 5V 선을 충분한 폭으로 배선하고, I2C선은 MQ 5V 및
AO_RAW 배선에서 떨어뜨린다. 네 센서가 하나의 다핀 커넥터를 공유하지
않게 하면 고장 센서만 분리하기 쉽다.

## 기판 배치 예시

실제 구멍 수는 가진 만능기판에 맞춰 조정하되 기능 영역의 순서는
유지한다.

### 기판 A 실장면 예시

```text
┌─────────────────────────────────────────────────────────────┐
│ [5V_SENSOR_IN] [5V/GND 안정화 자리]   TP_5V  TP_GND        │
│                                                             │
│ [A_MQ135]--10k--+--TP_MQ135_ADC--GPIO34     [ESP32 헤더]    │
│                 +--15k--GND                                 │
│                                                             │
│ [A_MQ2]----10k--+--TP_MQ2_ADC----GPIO33      GPIO26 예약    │
│                 +--15k--GND                  GPIO35 예약    │
│                                                             │
│ [A_FLAME]---------------------------GPIO27                   │
│ [A_TOF]------SDA--------------------GPIO21                   │
│              SCL--------------------GPIO22                   │
│              3V3/GND 버스       TP_3V3                      │
└─────────────────────────────────────────────────────────────┘
```

- 5V 전원 입력과 MQ 커넥터는 같은 쪽에 둔다.
- 두 분압 회로와 ADC 테스트 포인트는 ESP32 ADC 핀 가까이에 둔다.
- I2C SDA/SCL은 5V 전원 입력과 MQ AO_RAW 선에서 떨어뜨린다.
- ESP32를 직접 납땜하기보다 소켓헤더를 사용하면 교체가 쉽다.
- GPIO26과 GPIO35 주변에는 다른 신호를 배치하지 않고 라벨을 남긴다.

### 기판 B 실장면 예시

```text
┌───────────────────────────────────────────────────────┐
│ 기판 A 방향                                           │
│ [IN_MQ135]============================[J_MQ135]        │
│ [IN_MQ2]  ============================[J_MQ2]          │
│                                                       │
│ [IN_FLAME]----------------------------[J_FLAME]        │
│ [IN_TOF]  -3V3-GND-SDA-SCL------------[J_TOF]          │
│                                                       │
│  O 스트레인 릴리프 홀              고정 홀 O          │
└───────────────────────────────────────────────────────┘
```

- MQ 센서 커넥터와 VL53L1X 커넥터 사이에 간격을 둔다.
- 케이블이 납땜부를 직접 당기지 않도록 케이블타이용 구멍을 둔다.
- 모든 입력·출력 커넥터에 센서명과 핀 1을 양면 표시한다.

## 테스트 포인트

기판 A에 다음 테스트 포인트를 만든다.

| 테스트 포인트 | 측정 목적 |
|---|---|
| TP_5V | 외부 MQ 센서 전원 확인 |
| TP_3V3 | KY-026/VL53L1X 전원 확인 |
| TP_GND | 멀티미터 공통 기준 |
| TP_MQ135_ADC | GPIO34 입력 전압 확인 |
| TP_MQ2_ADC | GPIO33 입력 전압 확인 |

테스트 포인트는 프로브가 미끄러져 옆 패드와 단락되지 않게 충분한 간격을
둔다. ADC 테스트 포인트는 전원이 켜진 상태에서도 3.3V 이하이어야 한다.

## 케이블과 배선 배치

- MQ-135와 MQ-2의 5V/GND는 가능한 한 짧고 안정적으로 배선한다.
- MQ AO_RAW 선과 ADC 노드는 모터선, PWM선 및 USB 케이블에서 떨어뜨린다.
- SDA/SCL은 나란히 짧게 배선하고 MQ 히터 전원선과 평행하게 길게
  붙이지 않는다.
- 케이블을 교차해야 하면 가능한 한 직각으로 교차한다.
- 차체를 움직여도 커넥터에 직접 장력이 걸리지 않게 양 끝을 고정한다.
- 센서명과 방향을 케이블 양 끝에 모두 표시한다.
- 남는 선을 MQ 센서 히터 주위에 감아 두지 않는다.

## 납땜 순서

### 1단계: 방향과 핀 1 표시

1. 기판 A와 B의 실장면·납땜면을 표시한다.
2. 모든 커넥터 자리와 핀 1을 유성펜으로 표시한다.
3. ESP32 USB 커넥터 방향과 GPIO 번호를 표시한다.
4. 기판 A의 5V, 3.3V, GND 영역을 서로 다른 색으로 표시한다.

### 2단계: 전원과 GND 버스

1. GND 버스를 먼저 납땜한다.
2. 5V_SENSOR 버스를 별도로 납땜한다.
3. ESP32 3V3 버스를 별도로 납땜한다.
4. 세 버스 사이에 납땜 브리지가 없는지 확대해서 확인한다.
5. 멀티미터로 5V-GND, 3.3V-GND 및 5V-3.3V 단락 여부를 확인한다.

### 3단계: ESP32 헤더와 분압 회로

1. ESP32 소켓헤더를 정렬해 납땜한다.
2. MQ-135의 10kΩ 상단 저항을 AO_RAW 경로에 납땜한다.
3. 저항 뒤 ADC 노드를 GPIO34와 연결한다.
4. ADC 노드에서 15kΩ을 GND로 연결한다.
5. MQ-2도 같은 방식으로 GPIO33에 별도 분압을 만든다.
6. TP_MQ135_ADC와 TP_MQ2_ADC를 표시한다.

두 센서의 분압 중간점을 서로 연결하지 않는다.

### 4단계: 디지털과 I2C 신호

1. FLAME_DO를 GPIO27로 연결한다.
2. I2C_SDA를 GPIO21로 연결한다.
3. I2C_SCL을 GPIO22로 연결한다.
4. SDA/SCL 사이와 신호-GND 사이에 납땜 브리지가 없는지 확인한다.
5. GPIO26과 GPIO35가 비어 있는지 확인한다.

### 5단계: JST-XH 커넥터와 케이블

1. 기판 A의 센서별 출력 커넥터를 납땜한다.
2. 기판 B의 입력 및 센서 출력 커넥터를 납땜한다.
3. 케이블을 한 개씩 압착하고 양 끝 핀 번호를 확인한다.
4. 케이블을 연결한 뒤 같은 번호끼리 도통되는지 검사한다.
5. 각 케이블에 `MQ135`, `FLAME`, `TOF`, `MQ2` 라벨을 붙인다.
6. 케이블타이와 열수축튜브로 스트레인 릴리프를 만든다.

## 무전원 도통·단락 검사

ESP32, 네 센서, USB 및 외부 5V 전원을 모두 분리한 뒤 검사한다.

### 반드시 연결되어야 하는 경로

| 시작 | 끝 | 예상 |
|---|---|---|
| 5V_SENSOR_IN + | J_MQ135-1 | 도통 |
| 5V_SENSOR_IN + | J_MQ2-1 | 도통 |
| GND | 모든 센서 커넥터 2번 | 도통 |
| ESP32 3V3 위치 | J_FLAME-1 | 도통 |
| ESP32 3V3 위치 | J_TOF-1 | 도통 |
| J_MQ135-3 | 10kΩ 상단 입력 | 도통 |
| TP_MQ135_ADC | GPIO34 | 도통 |
| J_FLAME-3 | GPIO27 | 도통 |
| J_TOF-3 | GPIO21 | 도통 |
| J_TOF-4 | GPIO22 | 도통 |
| J_MQ2-3 | 10kΩ 상단 입력 | 도통 |
| TP_MQ2_ADC | GPIO33 | 도통 |

### 연결되면 안 되는 경로

| 경로 | 예상 |
|---|---|
| 5V_SENSOR ↔ GND | 단락 없음 |
| 3V3 ↔ GND | 단락 없음 |
| 5V_SENSOR ↔ 3V3 | 연결 없음 |
| TP_MQ135_ADC ↔ TP_MQ2_ADC | 연결 없음 |
| SDA ↔ SCL | 연결 없음 |
| GPIO26 ↔ 센서 신호 | 연결 없음 |
| GPIO35 ↔ 센서 신호 | 연결 없음 |

저항이 포함된 경로는 멀티미터 도통음 대신 저항값으로 확인해야 할 수 있다.

## 최초 전원 투입

### 1단계: ESP32와 센서 없이 기판만 확인

1. 모든 센서와 ESP32를 분리한다.
2. 전류 제한 기능이 있거나 상태가 확인된 5V 전원을 사용한다.
3. 외부 5V를 기판 A의 5V_SENSOR_IN에 연결한다.
4. TP_5V와 TP_GND 사이가 약 5V인지 확인한다.
5. 발열, 냄새 또는 전압 급락이 있으면 즉시 끈다.

### 2단계: ESP32만 연결

1. 외부 5V를 끈다.
2. ESP32를 소켓에 꽂고 USB에 연결한다.
3. TP_3V3와 TP_GND 사이가 약 3.3V인지 확인한다.
4. 외부 5V를 켜고 TP_5V를 다시 확인한다.
5. USB 5V와 외부 5V `+`가 서로 연결되지 않았는지 확인한다.

### 3단계: 센서를 하나씩 연결

다음 순서를 지키고 센서를 추가할 때마다 전원을 모두 끈다.

1. KY-026
2. MQ-135
3. VL53L1X
4. MQ-2

각 센서를 연결한 뒤 전압과 Serial 값을 확인하고 다음 센서로 넘어간다.
MQ-2를 연결한 뒤에는 두 MQ 히터가 동시에 동작할 때 TP_5V가 유지되는지
반드시 측정한다.

## v9 하드웨어 검증

### KY-026

- VCC=3.3V, GND=공통 GND, DO=GPIO27을 확인한다.
- Serial에서 `FLAME=NO/YES` 전환을 확인한다.
- v9는 LOW active이므로 필요하면 모듈 가변저항을 조절한다.

### MQ-135

- VCC=5V_SENSOR, GND=공통 GND를 확인한다.
- TP_MQ135_ADC가 3.3V 이하인지 확인한다.
- Serial에서 `GAS=<값>`과 `GAS_SENSOR=OK`를 확인한다.
- 분압 적용 전후 ADC 범위가 달라질 수 있으므로 실제 촬영 전에 가스
  임계값을 다시 확인한다.

### VL53L1X

- VIN=3.3V, GND=공통 GND, SDA=GPIO21, SCL=GPIO22를 확인한다.
- GPIO와 XSHUT은 연결하지 않는다.
- 부팅 시 `[VL53L1X] READY`를 확인한다.
- 약 700mm, 350mm, 150mm에서 `RAW_DIST`와 `DIST` 변화를 확인한다.
- 기본 I2C 주소는 `0x29`이며 외부 풀업 저항은 추가하지 않는다.

### MQ-2

- VCC=5V_SENSOR, GND=공통 GND를 확인한다.
- TP_MQ2_ADC가 3.3V 이하인지 확인한다.
- 깨끗한 공기에서 최소 3분간 예열한다.
- ESP32를 Reset하고 약 12초 기다린다.
- `MQ2_CAL=READY`, `MQ2_BASE`, `MQ2_DELTA`를 확인한다.

### 네 센서 동시 확인

Serial Debug에서 다음 값이 한 줄 안에서 계속 갱신되어야 한다.

| 센서 | Debug 필드 |
|---|---|
| MQ-135 | `GAS`, `GAS_SENSOR` |
| KY-026 | `FLAME` |
| VL53L1X | `RAW_DIST`, `DIST`, `DIST_SENSOR` |
| MQ-2 | `MQ2`, `MQ2_BASE`, `MQ2_DELTA`, `MQ2_CAL`, `MQ2_SENSOR` |

현재 RPi가 없으면 약 3000ms 뒤 `RPI_TIMEOUT` 정지가 발생하는 것이
정상이다. timeout 상태에서도 위 네 센서값은 계속 갱신되어야 한다.

현재 표시되는 `BAT=12.00V`는 실제 배터리 측정값이 아니라 v9에 남아 있는
고정 소프트웨어 값이다.

v9 송신 메시지 형식:

```text
<SENS,gas,flame,battCv,stateCode,actionCode,faultCode,distanceMm,mq2Raw,checksum>
```

## 차체 장착 원칙

### MQ-135와 MQ-2

- 센서 발열이 다른 기판이나 플라스틱에 직접 닿지 않게 간격을 둔다.
- 공기가 흐르는 차체 상단에 설치한다.
- 두 센서를 너무 가까이 붙여 열과 반응이 서로 영향을 주지 않게 한다.
- 센서 금속망을 테이프나 케이블로 막지 않는다.

### VL53L1X

- 로봇 전방을 향하게 하고 광학 창 앞을 비운다.
- 차체 부품, 케이블 또는 투명 보호판이 시야를 가리지 않게 한다.
- 반복 촬영 중 각도가 바뀌지 않게 단단히 고정한다.

### KY-026

- 화염 감지 소자가 시험 방향을 볼 수 있게 설치한다.
- MQ 센서의 뜨거운 부분과 간격을 둔다.
- 가변저항을 조절할 수 있는 방향으로 장착한다.

### 케이블

- 모터선과 센서선의 묶음을 분리한다.
- USB 케이블이 I2C 및 AO_RAW 선을 당기지 않게 고정한다.
- 모든 센서 케이블에 스트레인 릴리프를 적용한다.
- 차체 커버를 닫기 전에 커넥터 잠금과 핀 1 방향을 확인한다.

## 센서 교체 절차

1. ESP32 USB와 외부 5V 전원을 모두 끈다.
2. 교체할 센서의 양쪽 케이블 라벨을 확인한다.
3. JST-XH 하우징을 잡고 분리한다. 선만 잡아당기지 않는다.
4. 새 센서의 단자 순서가 기존 케이블과 같은지 확인한다.
5. 핀 1 표시를 맞춰 커넥터를 꽂는다.
6. 전원을 켜기 전 VCC-GND 단락 여부를 확인한다.
7. 해당 센서만 먼저 연결해 전압과 Serial 값을 확인한다.
8. 나머지 센서를 연결하고 네 값의 동시 갱신을 확인한다.

## 문제 해결

### 두 MQ 센서를 켜면 ESP32가 재부팅됨

- TP_5V를 측정해 전압 강하를 확인한다.
- 외부 5V 전원의 전류 여유와 케이블 접촉을 확인한다.
- MQ 센서가 3V3 버스에 연결되지 않았는지 확인한다.
- USB 5V와 외부 5V가 잘못 직결되지 않았는지 확인한다.

### MQ ADC 값이 0 또는 최대치에 고정됨

- `AO_RAW → 10kΩ → ADC 노드 → GPIO` 경로를 확인한다.
- ADC 노드에서 15kΩ이 GND로 연결됐는지 확인한다.
- TP_MQ135_ADC 또는 TP_MQ2_ADC가 3.3V 이하인지 측정한다.
- 두 ADC 노드가 서로 납땜 브리지로 연결되지 않았는지 확인한다.

### KY-026이 계속 감지 상태임

- AO가 아니라 DO가 J_FLAME-3과 GPIO27로 연결됐는지 확인한다.
- 센서 전원이 3.3V인지 확인한다.
- v9의 LOW active 조건에 맞게 가변저항을 조절한다.

### VL53L1X 초기화 실패

- J_TOF 핀 3=SDA=GPIO21, 핀 4=SCL=GPIO22인지 확인한다.
- 커넥터의 좌우 반전 여부를 확인한다.
- 센서 6핀 헤더의 납땜 브리지와 냉납을 확인한다.
- GPIO와 XSHUT이 연결되지 않았는지 확인한다.

### MQ-2가 보정을 완료하지 못함

- 최소 3분 예열 후 ESP32를 Reset했는지 확인한다.
- 약 12초 동안 기다렸는지 확인한다.
- `MQ2_SENSOR=ERROR`이면 J_MQ2, 분압 및 GPIO33 경로를 확인한다.

### 센서값은 정상이지만 `RPI_TIMEOUT` 표시

RPi가 없는 현재 구성의 정상적인 안전 fallback이다. 배선 검증은 각
센서 Debug 필드가 계속 갱신되는지로 판단한다.

## 반복 촬영 전 체크리스트

### 전기

- [ ] TP_5V가 약 5V이고 두 MQ 센서 동작 중에도 유지된다.
- [ ] TP_3V3가 약 3.3V이다.
- [ ] 모든 GND가 공통이다.
- [ ] USB 5V와 외부 5V `+`를 임의로 직결하지 않았다.
- [ ] TP_MQ135_ADC와 TP_MQ2_ADC가 모두 3.3V 이하이다.
- [ ] GPIO26은 Emergency Stop용으로 유지됐다.
- [ ] GPIO35는 LiPo 측정용으로 비어 있다.

### 커넥터와 기구

- [ ] J_MQ135, J_FLAME, J_TOF, J_MQ2의 핀 1 방향이 맞다.
- [ ] 모든 케이블 양 끝에 센서명 라벨이 있다.
- [ ] 모든 케이블에 스트레인 릴리프가 적용됐다.
- [ ] 센서 한 개를 다른 커넥터를 건드리지 않고 분리할 수 있다.
- [ ] MQ 센서 주위에 공기 흐름과 발열 간격이 있다.
- [ ] VL53L1X 전면 시야가 가려지지 않았다.

### 소프트웨어와 센서

- [ ] `[VL53L1X] READY`가 출력된다.
- [ ] MQ-2 예열과 Reset 후 `MQ2_CAL=READY`가 출력된다.
- [ ] `GAS`, `FLAME`, `DIST`, `MQ2`가 동시에 갱신된다.
- [ ] 센서 한 개를 자극해도 다른 세 센서값이 계속 갱신된다.
- [ ] `RPI_TIMEOUT`과 센서 오류를 구분할 수 있다.
- [ ] 실제 촬영 환경에서 MQ-135와 MQ-2 임계값을 확인했다.

## 최종 합격 기준

만능기판 배선은 다음 조건을 모두 만족하면 촬영용 프로토타입으로 합격한다.

1. 5V-GND, 3.3V-GND 및 5V-3.3V 사이에 단락이 없다.
2. 두 ADC 테스트 포인트가 어떤 정상 시험 상태에서도 3.3V를 넘지 않는다.
3. 네 센서값이 동시에 갱신된다.
4. 두 MQ 히터가 켜져도 ESP32가 재부팅되거나 USB가 끊기지 않는다.
5. 센서 한 개를 다른 센서 배선이나 두 기판을 탈거하지 않고 교체할 수 있다.
6. 모든 케이블에 센서명, 핀 1 및 스트레인 릴리프가 적용돼 있다.
7. 차체 장착 전에 커넥터별 도통 검사 결과를 기록했다.
