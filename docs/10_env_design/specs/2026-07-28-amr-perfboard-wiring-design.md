# HazardBot AMR 시연용 만능기판 배선 설계

## 목적

세 명의 팀원이 반복 촬영하여 안정적인 시연 영상 한 편을 완성할 수 있도록, 제작 난도와 현장 수리성을 우선한 센서 배선 구조를 사용한다.

## 확정 구조

기능별 만능기판 2장 구조를 사용한다.

1. 메인 전원·인터페이스 기판
   - ESP32 #1 신호 연결
   - 5V, 3.3V, GND 분배
   - LiPo 전압분배 및 ADC 연결
   - Emergency Stop 입력
   - I2C와 개별 센서 커넥터 분배
2. 센서 분배 기판
   - 차체 전면 센서 케이블 집선
   - 센서별 잠금형 커넥터 제공
   - 고장 난 센서를 개별적으로 분리·교체

카메라는 Raspberry Pi 5에 USB 또는 CSI로 직접 연결한다. ESP32 #1과 Raspberry Pi 5의 핵심 통신은 USB 직렬 연결을 사용한다.

## 대상 센서

- MQ-2
- MQ-135
- VL53L1X
- TCS34725
- MLX90614
- KY-026
- FC-37
- 5채널 IR 라인트레이싱 모듈
- LiPo 전압 측정 입력
- Emergency Stop

ESP32 #2 ARM, STS3215, 그리퍼 및 출력 장치는 이 기판의 범위에서 제외한다.

## 연결 원칙

- 센서는 만능기판에 직접 납땜하지 않고 JST-XH 계열 잠금형 커넥터로 연결한다.
- I2C 센서 3종은 공통 SDA/SCL 버스를 사용하되 각각 분리 가능한 4핀 커넥터를 둔다.
- 아날로그 센서와 모터 전원 배선은 I2C 및 USB 케이블에서 떨어뜨린다.
- MQ 센서는 발열과 공기 흐름을 고려해 차체 상단에 별도 고정한다.
- 라인트레이싱 센서와 FC-37은 차체 하단에서 높이 조절이 가능해야 한다.
- 배터리 측정 회로는 배터리 사양 확정 후 구성한다. 프로젝트 안전 기준은 3S LiPo cutoff 9.9V를 유지한다.
- 모든 케이블에는 스트레인 릴리프와 라벨을 적용한다.

## 성공 기준

- 주행 진동 중 센서 커넥터가 빠지지 않는다.
- 센서 한 개를 전체 기판 탈거 없이 교체할 수 있다.
- ESP32와 RPi 5 사이 USB 직렬 통신이 촬영 동안 유지된다.
- Emergency Stop, 센서 오류, LiPo cutoff 및 통신 timeout이 안전 정지를 유지한다.
- 현장에서 납땜 수정 없이 예비 센서나 예비 케이블로 교체할 수 있다.
