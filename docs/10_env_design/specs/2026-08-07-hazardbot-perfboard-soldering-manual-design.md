# HazardBot 만능기판 납땜 설명서 설계

## 목표

납땜 경험이 전혀 없는 초보자도 학교 실습실에서 교사 또는 성인의 감독 아래
HazardBot의 센서용 기판과 주행용 기판을 순서대로 제작할 수 있는 A4 PDF
설명서를 만든다. 설명서는 실제 부품 사진을 사실적으로 재현하는 것보다 기판의
방향, 점퍼선과 전원 레일의 위치, 고정대 사용법, 인두와 납을 대는 위치를 정확하게
보여주는 교육용 삽화를 우선한다.

최종 PDF는 한 파일이지만 센서용 기판과 주행용 기판을 명확하게 분리한다. 상세한
교과서형 설명과 작업대 옆에서 확인할 수 있는 요약 체크리스트를 함께 제공한다.

## 독자와 설명 원칙

- 대상 독자: 납땜을 한 번도 해보지 않은 초보자
- 목표 이해 수준: 12살이 읽어도 동작을 따라 할 수 있는 표현
- 한 단계에는 한 동작만 배치한다.
- 각 동작은 `지금 할 일 → 작업 전 상태 → 손과 도구 위치 → 실제 동작 → 성공한
  모습 → 흔한 실수 → 확인란` 순서로 설명한다.
- 전문 용어는 처음 등장할 때 쉬운 말과 함께 정의한다.
- 뜨거운 인두, 전원 인가, 모터 전원 작업은 교사 또는 성인의 감독 표시를 넣는다.
- 배선은 색만으로 구분하지 않고 핀 이름을 반복 표기한다.

## 결과물

- 형식: 인쇄 가능한 A4 PDF
- 예상 분량: 약 18~22페이지
- 구성: 표지, 공통 납땜 기초, 센서용 기판, 주행용 기판, 최종 검사 및 요약표
- 각 핵심 작업에는 위에서 본 배치, 아래에서 본 납땜면, 고정대에 끼운 옆모습,
  올바른 예와 잘못된 예를 포함한다.
- PDF 생성 후 모든 페이지를 이미지로 렌더링하여 잘림, 겹침, 작은 글자, 잘못된
  좌우 반전이 없는지 확인한다.

## 시각 체계

- 빨강: 5V 및 전원 양극
- 주황: 3.3V
- 검정: GND
- 파랑: 일반 센서 및 제어 신호
- 보라: MQ 센서 아날로그 신호와 분압회로
- 회색 점선: 연결하지 않는 핀
- 초록 테두리: 올바른 작업
- 빨강 테두리와 X: 잘못된 작업
- 손가락 표시: 잡아야 하는 부분
- 열 경고 표시: 인두 팁과 방금 납땜한 부분

실제 점퍼선 색이 다를 수 있으므로 모든 선에 `5V`, `3V3`, `GND`, `GPIO34`와
같은 기능 이름을 함께 표시한다.

## 문서 구성

### 1. 시작하기 전

- 완성할 두 기판의 역할
- 구매품과 기존 보유품
- 인두, 납, 고정대, 니퍼, 스트리퍼, 멀티미터의 역할
- 부품면과 구리면 구별
- 전원을 분리한 상태에서만 납땜해야 하는 이유
- 인두에서 잡아도 되는 부분과 만지면 안 되는 부분

### 2. 납땜 연습

- 실제 회로에서 떨어진 기판 모서리를 연습 구역으로 지정
- 인두 예열과 팁 주석 도금
- 구리 패드와 금속선을 동시에 데우는 방법
- 납 공급, 납 제거, 인두 제거의 순서
- 식는 동안 움직이지 않는 방법
- 정상 납땜, 납 부족, 납 과다, 냉땜, 인접 패드 합선 비교

### 3. 암헤더와 ESP32

- 20핀 암헤더의 끝 한 칸을 희생하여 19핀으로 만드는 방법
- 암헤더 두 줄을 ESP32에 먼저 꽂아 간격을 맞추는 방법
- USB 포트가 기판 밖을 향하도록 배치
- 대각선 모서리 핀만 먼저 납땜하고 수직을 확인한 뒤 나머지를 납땜
- 배선 작업 전 ESP32를 소켓에서 빼는 시점

### 4. 센서용 기판

- MQ-135, MQ-2, KY-026, VL53L1X의 단순화된 배치
- MQ 금속 망을 가리지 않고 VL53L1X 렌즈를 전방으로 향하게 하는 고정법
- 기존 암-암 점퍼선을 잘라 센서용 피그테일로 만드는 방법
- 5V, 3.3V, GND 레일의 위치와 필요한 접점 수
- 부품면에서 센서선을 먼저 구멍에 넣고 납땜면에 레일선을 놓는 순서
- 센서선, 구리 패드, 레일선을 한 납땜점에서 연결하는 방법
- MQ 센서 두 개의 10kΩ/20kΩ 분압회로
- 한 센서씩 연결하고 검사하는 방법
- V10 업로드 및 센서별 확인 순서

### 5. 주행용 기판

- 두 번째 ESP32 암헤더 장착
- TB6612FNG와 라인센서의 단순화된 배치
- TB6612FNG와 라인센서를 기존 점퍼선으로 연결하고 기판에 물리적으로 고정
- 3.3V 로직 레일과 로직 GND 레일
- 기존에 성공한 제어 핀 배선의 이전
- VM 12V, 전력 GND, A01/A02, B01/B02는 얇은 점퍼선이나 로직 레일을
  통과시키지 않고 기존 직접 연결을 유지
- USB와 로직 시험 후 바퀴를 띄우고 모터 전원을 연결하는 순서

### 6. 마지막 검사

- 모듈을 꽂기 전 육안 검사와 멀티미터 검사
- 5V-GND, 3.3V-GND 단락 확인
- 휴대폰 카메라 확대 검사
- 센서 기판과 주행 기판의 분리 시험
- 촬영 직전 한 장 체크리스트

## 센서 기판 배선 정본

### 전원

| 레일 | 소스 | 연결 대상 |
|---|---|---|
| 5V | ESP32 5V/VIN | MQ-135 VCC, MQ-2 VCC |
| 3.3V | ESP32 3V3 | KY-026 VCC, VL53L1X VIN |
| GND | ESP32 GND | 센서 4개 GND, 두 20kΩ 저항의 GND 쪽 |

### 신호

| 센서 | 연결 |
|---|---|
| MQ-135 AO | 10kΩ → 분압 중점 → GPIO34 |
| MQ-135 분압 중점 | 20kΩ → GND |
| MQ-2 AO | 10kΩ → 분압 중점 → GPIO35 |
| MQ-2 분압 중점 | 20kΩ → GND |
| KY-026 DO | GPIO27 |
| VL53L1X SDA | GPIO21 |
| VL53L1X SCL | GPIO22 |

MQ 센서 DO, KY-026 AO, VL53L1X INT와 XSHUT은 연결하지 않는다.

## 주행 기판 배선 정본

### TB6612FNG 로직

| TB6612FNG | ESP32 |
|---|---|
| PWMA | GPIO25 |
| AIN1 | GPIO26 |
| AIN2 | GPIO27 |
| PWMB | GPIO14 |
| BIN1 | GPIO16/RX2 |
| BIN2 | GPIO17/TX2 |
| STBY | GPIO4 |
| VCC | 3.3V |
| 로직 GND | GND |

### 라인센서

| 라인센서 | ESP32 |
|---|---|
| VCC | 3.3V |
| GND | GND |
| S1 | GPIO13 |
| S2 | GPIO18 |
| S3 | GPIO19 |
| S4 | GPIO23 |
| S5 | GPIO32 |

TB6612FNG의 VM 12V, 전력 쪽 GND, A01/A02, B01/B02는 만능기판의 얇은
점퍼선과 로직 전원 레일에 넣지 않는다. 기존에 시험한 직접 연결을 유지하고
설명서에는 `이번 납땜 작업에서 변경하지 않음`으로 표시한다.

## 부품 사용 범위

- 단면 100×100mm, 2.54mm 만능기판 2개
- 20핀 2.54mm 암헤더 4개를 각각 19핀으로 가공하여 두 ESP32에만 사용
- TB6612FNG와 센서 모듈은 소켓을 추가하지 않고 기존 점퍼선을 사용
- 보유 중인 10kΩ, 20kΩ 저항 사용
- 보유 중인 점퍼선을 센서 및 로직 배선과 전원 레일 재료로 재사용

## 작업 순서와 검사 정책

1. 전원과 모든 모듈을 분리한다.
2. 빈 기판에서 납땜 연습을 한다.
3. ESP32를 정렬 지그로 사용해 암헤더 모서리만 먼저 납땜한다.
4. 수직을 확인한 후 헤더의 나머지 핀을 납땜한다.
5. ESP32를 빼고 센서선과 로직선을 배치한다.
6. 부품면에서 선을 먼저 넣고 납땜면에서 공통 레일을 놓아 함께 납땜한다.
7. 한 연결을 만들 때마다 육안으로 확인하고, 한 기능 블록이 끝날 때마다
   멀티미터로 도통과 단락을 검사한다.
8. 모듈을 모두 빼고 최종 단락 검사를 한다.
9. ESP32만 꽂아 USB 전원으로 부팅을 확인한다.
10. 센서 기판은 센서를 하나씩 추가한다.
11. 주행 기판은 로직을 먼저 확인하고 마지막에 바퀴를 띄운 상태로 기존 모터
    전원을 연결한다.

## 완료 기준

- PDF에서 센서용 기판과 주행용 기판이 제목, 색상, 페이지 구성으로 명확히
  분리되어 있다.
- 초보자가 기판의 부품면과 납땜면, 고정대 방향, 인두와 납의 위치를 그림만 보고
  구별할 수 있다.
- 센서 및 주행 핀 배선표가 프로젝트의 확정값과 일치한다.
- 5V, 3.3V, GND, 12V 모터 전원이 서로 혼동되지 않는다.
- 실제 보유품 외에 새로운 부품을 필수로 요구하지 않는다.
- 모든 페이지를 렌더링해 내용 잘림, 그림 겹침, 좌우 반전 오류가 없음을 확인한다.
