# HazardBot 전원 및 배터리 요구사항

## 목적

이 문서는 HazardBot AMR의 배터리 구매 전 기준을 정리한다. 현재 팀이 실제 배터리를 아직 구입하지 않은 상태이므로, LiPo 전압 측정 코드를 확정하기 전에 전원 구조와 배터리 요구사항을 먼저 정해야 한다.

## 현재 확인된 정보

현재 확인된 구동 부품은 `DC 12V 350rpm` 모터다. 모터 단자는 다음처럼 표기되어 있다.

```text
M2, V, A, B, G, M1
```

의미는 다음일 가능성이 높다.

| 표기 | 추정 역할 |
|---|---|
| `M1`, `M2` | 모터 전원 단자 |
| `V` | 엔코더 전원 + |
| `G` | 엔코더 GND |
| `A`, `B` | 엔코더 신호 |

이 정보는 배터리 정보가 아니라 모터/엔코더 정보다. 배터리 라벨은 아직 확인되지 않았다.

ICBANQ 제품 정보 기준으로 모터 정격 전류는 `1.5A`이다. 좌우 모터 2개를 사용한다면 정격 부하 기준으로 모터만 약 `3.0A`가 필요하다. 실제 출발, 회전, 장애물 접촉, 바퀴 stall 상황에서는 이보다 더 큰 순간 전류가 필요할 수 있다.

## 배터리 후보

모터가 12V 계열이므로 배터리 후보는 다음이 적절하다.

| 후보 | 장점 | 주의점 |
|---|---|---|
| 3S LiPo 11.1V | 모터 12V 계열과 잘 맞고 출력이 좋음 | 충전/보관/과방전 관리 필요 |
| 3S Li-ion pack 11.1V 또는 12V | BMS 포함 제품 선택 가능 | 순간 방전 성능 확인 필요 |

현재 코드의 cutoff 기준 `9.9V`는 3S 기준 셀당 약 `3.3V`이므로 3S 배터리와 잘 맞는다.

## 구매 전 확인할 사양

배터리 구매 전 다음 항목을 확인한다.

- 전압: `3S`, `11.1V nominal`, 완충 `12.6V`
- 용량: 최소 `2200mAh` 이상 권장, 실제 주행 시간 목표에 따라 조정
- 방전율: 모터 최대 전류를 감당할 수 있는 C-rate 또는 최대 방전 전류
- 커넥터: 모터 드라이버/전원 분배와 맞는 커넥터인지 확인
- 보호회로: Li-ion pack은 BMS 포함 여부 확인
- 충전기: 배터리 타입에 맞는 전용 충전기 필요

현재 모터 정보 기준으로 배터리와 전원부는 최소 다음 조건을 만족해야 한다.

- 모터 2개 정격 전류 합계 `3A` 이상을 감당할 것
- RPi 5, ESP32, 센서류 전류를 추가로 감당할 것
- 출발/급정지/stall 상황의 순간 전류 여유를 둘 것
- 모터 드라이버가 모터 1개당 `1.5A` 정격 전류를 안정적으로 처리할 것

따라서 배터리 방전 전류는 단순히 `3A`에 맞추지 말고 여유를 두어 선정한다. 실제 모터 stall current가 확인되면 그 값을 기준으로 다시 계산해야 한다.

## 전원 구조 권장안

권장 전원 흐름은 다음과 같다.

```text
배터리
 ├─ 모터 드라이버 VM 입력
 ├─ DC-DC Buck 5V → Raspberry Pi 5
 └─ DC-DC Buck 5V 또는 3.3V → ESP32
```

중요 조건:

- ESP32, 모터 드라이버, RPi 5의 GND 기준은 공통으로 맞춘다.
- 모터 전원을 ESP32 핀에서 직접 공급하지 않는다.
- RPi 5는 전류 소모가 크므로 안정적인 5V 전원 모듈을 사용한다.
- 모터 노이즈가 ESP32/RPi 5에 영향을 주지 않도록 배선과 전원 분리를 고려한다.

## LiPo 전압 측정 계획

배터리가 확정되기 전까지 v7 펌웨어의 `currentBatteryVoltage = 12.0` 임시값은 유지한다. 배터리와 저항값이 확정되면 전압 분배 회로를 추가하고 `readBatteryVoltage()`로 교체한다.

추천 시작안:

```text
R1 = 100kΩ
R2 = 33kΩ
ADC 핀 후보 = GPIO35
```

단, 실제 ESP32 보드에서 GPIO35가 비어 있는지 먼저 확인해야 한다. 현재 `MQ135_PIN = 34`이므로 GPIO34는 사용하지 않는다.

## 구매 후 검증 절차

배터리 구매 후 다음 순서로 확인한다.

1. 멀티미터로 배터리 전압을 측정한다.
2. 전압 분배 회로 출력이 ESP32 ADC 허용 범위 안인지 확인한다.
3. ESP32가 출력하는 `BAT=` 값과 멀티미터 값을 비교한다.
4. `BAT <= 9.9V`일 때 `STATE=STOP`으로 전환되는지 확인한다.
5. 모터 구동 중 전압 강하가 발생해도 시스템이 불안정해지지 않는지 확인한다.

## 지금 할 수 있는 과업

배터리 구매 전에는 다음 작업을 우선한다.

- 모터 드라이버 전류 여유 검토
- 모터 stall current 확인
- RPi 5 전원 모듈 선정
- E-Stop 버튼 배선 확정
- 엔코더 `A/B` 입력 설계
- AMR 상태 전환 발표자료 정리

## 결정해야 할 항목

팀에서 다음 값을 확정해야 한다.

- 사용할 배터리 타입: LiPo 또는 Li-ion pack
- 배터리 용량
- 최대 방전 전류
- 커넥터 종류
- 충전기
- 전원 분배 방식
- ESP32 LiPo 측정 ADC 핀
