## §1. 파지 방식 — 둘 다 ACT 유지 〔재확인 2026-08-09〕

### 1.1 왜 다시 검토했는가

물체가 **적색 = 3D 프린팅 PLA 원기둥 / 황색 = 노란색 종이컵**으로 확정되면서,
8/4 의 「적색 프리셋 / 황색 ACT」를 되살릴 여지가 있는지 다시 봤다.

**결론: 되살리지 않는다. 재질 확정은 오히려 「둘 다 ACT」를 강화한다.**

### 1.2 🔴 8/4 안의 전제 3개가 이미 무너져 있다

| # | 8/4 당시 전제 | 2026-08-09 현재 | 출처 |
|---|---|---|---|
| 1 | "프리셋은 이미 서 있는 안전한 선택지" | 🔴 **거짓.** `center_x`/`center_y` 는 발행만 되고 **소비처가 없다**. `arm_controller` 는 포즈 테이블로 축소됐고 **정지 산포도 미측정** | `시연장_배치` §6.4-③ · 정본 §8.1-14 · §9-14 〔종전 §9-9 · 8/14 번호 정리〕 |
| 2 | "변형체라서 ACT가 필요하다" | 🔴 **거짓.** 종이컵은 **공산품이라 매번 같고**, 축대칭 + 링 + 높이 상수라 **자세 추정 난이도가 소분 용기와 같다**. 게다가 **ACT는 위치 제어라 압착을 못 막는다** | `시연장_배치` §6.4-① |
| 3 | "원테이크에 ACT 파지 2회는 위험하다" | 🔴 **소멸.** 8/6 에 무편집 원테이크를 포기했고, `/mission/start` 로 **노드 재시작 없이 반복 촬영**이 된다 | 정본 §0-10 · §7.5 |

**①이 특히 중요하다.** 「적색 프리셋」을 고르는 순간 안전한 선택이 아니라
**VGR 소비 구현 + 정지 산포 실측 + 오프셋 캘리브레이션이라는 새 작업 갈래**가 열린다.
반면 적색을 ACT 에 넣는 한계비용은 **같은 수집 세션에 적색 에피소드를 추가하는 것뿐**이다 —
정책 1개, 학습 1회는 어느 쪽이든 동일하다.

D-26 시점에 **ACT 추론 루프**(정본 §8.1-13, 규모 **대**)와
**DRIVE TCP 클라이언트**(정본 §8.2-1, 규모 **대**)가 통째로 비어 있다.
여기서 파지 제어 경로를 둘로 벌리면 **실패 모드를 두 세트 디버깅**해야 한다.

### 1.3 🔵 재질 확정은 「둘 다 ACT」에 유리하다

**PLA 원기둥은 ACT 에게 가장 쉬운 대상이다.**

| 특성 | ACT 관점의 의미 |
|---|---|
| 강체 (하드스톱 있음) | 과닫힘을 물체가 흡수 → 위치 제어의 약점이 드러나지 않는다 |
| 회전 대칭 원기둥 | **각도 축이 없다** → 변동 축이 x·y 뿐, 수집 에피소드가 적게 든다 |
| 3D 프린팅 출력물 | 🔵 **테이크마다 외형이 완전히 동일** → 입력 픽셀 분포가 흔들리지 않는다 |
| 재사용 가능 | 수집·시험 반복 비용 0 (종이컵은 1회성) |

> **황색 종이컵이 8/21 게이트(10회 중 8회)를 통과하는 정책이라면, PLA 원기둥은 거의 확실히 통과한다.**
> 즉 「둘 다 ACT」의 추가 리스크는 **사실상 컵 하나에 수렴**하고,
> 그 컵은 **어느 안을 골라도 ACT** 다. 적색을 빼서 줄어드는 리스크가 거의 없다.

🔲 **PLA 표면 미끄러짐**은 🔵 **그리퍼 골무**〔8/9 · ~~폼 패드~~〕가 처리한다 — 목적이 **파지력 향상**이다.
🔴 **골무는 수집 전에 끼운다** — 나중에 끼우면 두께만큼 개구가 줄어 **적색 데이터까지 무효**가 된다.
🔴 **그리고 그리퍼 최대 개구 실측을 골무 낀 상태로 한다** (`demo_set_build_plan` §5.1 ①).

### 1.4 🔵 폴백 포함 관계 — 이 선택이 우월한 결정적 이유

```
   「둘 다 ACT」  ──8/21 적색 미달──▶  적색만 프리셋+VGR  =  8/4 구성
   「8/4 구성」   ──────────────────▶  (역방향 없음)
```

**「둘 다 ACT」는 8/4 구성을 폴백으로 품고 있지만, 역은 성립하지 않는다.**
8/4 로 먼저 가면 적색 ACT 를 나중에 얹기 위해 수집을 다시 해야 한다.

| 8/21 판정 결과 | 조치 |
|---|---|
| 둘 다 8/10 이상 | 🔵 그대로 진행 |
| 황색만 미달 | 황색 프리셋 + VGR (적색 ACT 유지) |
| **적색만 미달** | **= 8/4 구성으로 하강.** 적색 프리셋 + VGR |
| 둘 다 미달 | 전량 프리셋 + VGR. ACT 는 데이터셋·학습 곡선을 **연구 성과로** 발표 |

### 1.5 발표 서사는 손해가 없다

8/4 안의 강점이던 *"학습은 불확실성이 있는 곳에만 쓴다"* 는 문장을 잃지만,
**더 정직하고 방어력이 높은 문장 3개로 대체된다.**

| 대체 주장 | 근거 |
|---|---|
| 🔵 **"VGR 과 ACT 는 직렬이다"** — 접근 오차는 **산업 표준 비전 보정**이 접고, 마지막 폐루프 파지만 학습이 맡는다 | VGR 을 빼면 ±30mm 전 범위를 데이터로 덮어야 해 에피소드가 몇 배로 뛴다 (`시연장_배치` §6.2). **학습의 사용 범위를 절제했다는 증거가 여기 남는다** |
| 🔵 **"단일 정책이 손목 카메라 픽셀만으로 두 물체를 구분해 다른 파지를 수행한다"** | ACT 는 언어 조건이 없는 단일 태스크 정책이다 (`시연장_배치` §6.6). **정책 2개 스위칭보다 기술적으로 강한 주장** |
| 🔵 **"컵 압착은 ACT 가 아니라 결정론적 안전층이 막는다"** 〔8/9 개정 · ~~폼 패드 + 무게추~~〕 — **단단한 컵 + Load 클램프 40%** | ACT 는 위치 제어라 힘 피드백이 없다는 **한계를 알고 설계했다**는 증거. 🔵 **소품이 빠지면서 클램프가 실제 주체가 되어 주장이 스스로 선다.** **Q&A 최강 방어** (§5-Q3) |

프리셋과의 비교는 **기존대로 심층 구간 분할화면**(찌그러진 컵 vs 성공)에서 보여준다.

## §2. 복귀(`RETURN`) — 동작은 확정됐고, 표현을 정한다

**동작은 정본 §4.2 에서 이미 확정**됐다. `RETURN` 신설(하트비트 유지 · 부저 ON · 자동 해제). 이 절은 **말하는 방식**만 정한다.

> 🔴 **2026-08-09 — 이탈 방향이 전진에서 후진으로 바뀌었다** (정본 §4.2.1).
>
> ~~화재 구역을 스테이션 직전에 배치해 전진 그대로 복귀 20초~~ → **폐기.**
> 🔴 **이 절이 세운 논리 자체가 그 동작과 모순이었다** — §0-5 가 *"로봇 자신이 점화원 후보"* 라고
> 해 놓고, 정작 로봇은 **점화원을 들고 화염 쪽으로 갔다.** 후진으로 바뀌면서 **말과 동작이 맞았다.**
>
> 🔴 **표현도 함께 바뀐다** — 「안전구역 복귀」는 **도착**을 뜻하는데 후진 이탈은 **이격만** 한다.
> 🔵 **「점화원 이탈 · 관제 보고」**로 쓴다.

### 2.1 🔴 명칭 — "충전"이라 부르지 않는다

| ❌ 쓰지 않는다 | ✅ 쓴다 |
|---|---|
| "충전 스테이션으로 복귀합니다" | 🔵 **"경보를 울리고 뒤로 물러나며 관제에 보고합니다"** |
| 🔴 **"안전구역으로 복귀합니다"** 〔8/9 추가〕 | 🔵 자막·표기는 **「점화원 이탈 · 관제 보고」** |
| 로봇이 스스로 복귀해 충전하는 듯한 표현 | ~~"스테이션 대기 위치로 복귀"~~ 🔴 **스테이션까지 가지 않는다** |
| 🔴 후진을 **"자율 회피 주행"**이라 부르는 것 | **"정해진 거리만큼 물러난다"** — 라인을 따라가지 않고 후방 감지도 없다 |

🔴 **「안전구역 복귀」가 왜 안 되는가** — **도착**을 뜻하는데 후진 이탈은 **이격만** 한다.
그리고 이 문서 §0-4 · `demo_video_scenario` §12 · 공유본 정직성 목록이 모두 같은 문구를 쓴다.

**이유**: 자동 도킹 충전은 구현하지 않는다(3S LiPo 밸런스 충전 필요).
"충전 복귀"라고 말하면 **없는 기능을 시사**하게 되어 `docs/03_scenario_demo/demo_video_scenario.md` §12 정직성 규칙과 충돌한다.

### 2.2 🔵 복귀는 도망이 아니라 표준 대응이다 — 논리 2단

**1단. 화재 시 로봇의 역할은 감지 · 경보 · 이탈이다.** 진압은 고정 소화 설비와 사람의 몫이다.

**2단. 🔵 로봇 자신이 점화원 후보다.**
브러시 DC 모터로 구동되는 AMR 은 가연성 분위기에서 **점화원**이다.
따라서 이탈은 자기 보호가 아니라 **"현장에서 점화원 하나를 제거하는 안전 조치"** 다.

> 이 프레임이면 *"왜 불을 끄지 않습니까"* 라는 질문이 **이해도를 증명할 기회로 바뀐다.**
> 정본 §1.3 의 인과(가연성 증기 + 점화 에너지 = 폭발)와도 그대로 이어진다.

### 2.3 화면에서 읽히게 하는 법

| 채널 | 내용 | 산업 대응물 |
|---|---|---|
| **부저** (`<BUZZ,1>`) | 현장 경보 | 현장 음향 경보기 |
| **대시보드** | 관제 통보 · `RETURN` 상태 표시 | 관제실 알람 |
| **자막 1줄** | *"주행 능력이 살아 있어야 하는 비상이므로 정지가 아니라 복귀한다"* | `RETURN` ≠ `EMERGENCY` |

🔵 **부저 + 대시보드의 이중 채널**이 "현장 경보 + 관제 보고"라는 산업 서사를 완성한다.
비상을 2종으로 분리한 설계(정본 §4.2)가 **화면에서 읽히는 것은 이 자막 한 줄에 달려 있다.**

## §3. 도입 서사 — 24시간 Fab 안전관리 〔신규〕

영상 도입 20초와 PPT 첫 장의 내용이다. 정본 §1 은 **세계관**(인화성 물질 취급 구역)을 정했고,
이 절은 **"왜 이 프로젝트인가"** 를 정한다.

### 3.1 🔵 3단 논법

```
 ① Fab 은 24시간 가동된다  →  안전관리도 24시간이어야 한다
                              그런데 순찰 인력은 24시간이 아니다
 ─────────────────────────────────────────────────────────────
 ② 그래서 AI 순찰 로봇이 이미 현장에 투입되고 있다
    SK하이닉스 이천캠퍼스의 4족 보행 순찰 로봇 「가온」·「다온」
    → 자율주행으로 순찰하며 가스 누출·온도 이상을 실시간 통보
    → 자동 충전 시간을 제외하면 24시간 가동
 ─────────────────────────────────────────────────────────────
 ③ 🔵 그러나 이들의 역할은 「감지와 통보」까지다
    HazardBot 은 격납이 깨진 용기를 직접 격리하는
    「초동 조치」까지 수행하는 다음 단계를 제안한다
```

**②가 하는 일**: *"이게 실제로 되는 일이냐"* 는 의심을 **실존 선례로 지운다.**
**③이 하는 일**: 매니퓰레이터를 얹은 이유 = **프로젝트의 존재 이유**가 된다.

> 한 줄 요약: **감지 → 판정 → 조치 → 기록의 폐루프를 로봇 혼자 닫는다.**
> 고정 센서·CCTV·순찰 로봇이 「감지」에서 멈추는 자리를 HazardBot 이 이어받는다.

### 3.2 🔴 인용 수위 — 로봇은 실명, 사고는 익명

| 대상 | 수위 | 이유 |
|---|---|---|
| 가온 · 다온 | 🔵 **실명 인용 가능** | 공개된 홍보 자료다. 선행 사례로 드는 것은 문제없다 |
| 2026년 반도체 사업장 가스 누출·화재 사고 | 🔴 **익명화** — *"최근 국내 반도체 사업장에서"* | 특정 기업을 **사고와 로봇 양쪽에 걸치면 공격적으로 읽힌다** |
| 우리 세트 | 🔴 **"Fab 재현"이라고 하지 않는다** | 캔들·소분 용기 세트는 Fab 이 아니다. 정본 §1.1 의 **「인화성 물질 취급 구역」을 유지**한다 |

**사고 인용이 유효한 이유**: 가스 배관 작업 중 **불꽃(점화원)** 에 의한 화재·가스 누출이라
정본 §1.3 의 인과 구조와 **정확히 같다.** 필요성 근거로 강력하다.

**모티브의 사용 범위**: 🔵 **도입부와 PPT 까지.** 세트·자막은 정본의 세계관 어휘를 그대로 쓴다.
Fab 의 가스·케미컬 공급 구역에도 인화성 가스(실란·수소 등)가 있어 논리는 이어지지만,
**세트가 Fab 이라고 주장하지는 않는다.**

## §4. 발표용 — "왜 ACT 인가" 4겹

문서 곳곳에 흩어진 근거를 **발표 순서**로 재조립한 것이다. 새 결정은 없다.

| 겹 | 주장 | 근거 |
|---|---|---|
| **1** | **왜 학습인가** — 규칙이 실패하는 지점이 실제로 있다 | 파지 대상의 위치는 **차체 정지 산포(±30mm)의 함수**라 사전에 알 수 없다. 정밀 도킹 설비 없이 이 오차를 흡수해야 한다 |
| **2** | **왜 정밀 주행 대신인가** — 저가 하드웨어의 산포를 지능으로 흡수 | 엔코더 없는 AMR 은 매번 같은 자리에 서지 못한다. **접근은 마커·VGR 이, 마지막 수 cm 는 손목 카메라 ACT 가** 흡수한다. *"차체가 정확히 설 필요가 없다 — 어긋난 만큼 팔이 본다"* |
| **3** | **왜 하필 ACT 인가** — 엣지에서 도는 유일한 구조 | **Action Chunking(chunk_size=100)** — 추론 1회가 미래 100스텝. 30Hz 제어 기준 **1회 = 3.3초 분량**이라 추론이 1Hz 여도 제어는 30Hz 로 돈다. **GPU 서버 없이 RPi 5 온보드에서 학습 정책이 돈다** → 24시간 무인 현장(클라우드 두절에도 동작)과 직결 |
| **4** | **학습 + 결정론적 안전층** — 산업 적용의 정석 | ACT 출력 위에 **STS3215 Load 세이프티 클램프**(적 80% / 황 40%)가 실시간으로 얹힌다. *"신경망 출력을 그대로 믿지 않고 결정론적 안전장치로 감쌌다"* |

🔵 **텔레옵 수집 장면의 서사** — *"숙련 작업자의 동작을 로봇에 이식한다"* (기능 전수).
**"이 동작을 사람이 가르쳤다"는 영상만이 전달할 수 있다.**

🔴 **한계는 선제적으로 말한다** — 정책이 픽셀에서 학습하므로 **조명·배치에 민감**하다
(그래서 「수집 조명 = 촬영 조명」 규칙이 존재한다). **성공률 실측치는 영상과 별도로 정직하게 기록**한다.

## §6. 구역 개념 제거 — 취급구역 하나 + 점검점 〔신규 2026-08-09〕

> **전체 세트가 「인화성 물질 취급·보관 구역」 하나다. 내부를 Zone 으로 나누지 않는다.**
> 상세 배치·벽 사양은 `docs/03_scenario_demo/시연장_배치_2026-08-15.md` §2. 이 절은 **왜 그렇게 정했는지**를 남긴다.

### 6.1 🔴 Zone 은 로봇 동작이 아니라 기기 자격을 정하는 개념이다

| 체계 | 구분 기준 | **무엇을 결정하는가** |
|---|---|---|
| **KS C IEC 60079-10-1** | 폭발성 분위기의 존재 시간·빈도 | 🔴 반입 가능한 **방폭 기기 등급** (Ex ia / Ex d·e / Ex n) |
| **NFPA 70 (NEC) Art. 500** | Class I Div 1 / Div 2 | 🔴 동일 — **설비 선정 기준** |
| **위험물안전관리법** | 지정수량 배수 | 보유공지·소화설비 요건 |

```
   Zone 0   연속·장기간·빈번하게 존재   ← 가장 위험
   Zone 1   정상 운전 중 주기적으로 존재
   Zone 2   정상 운전 중 존재하지 않음   ← 가장 덜 위험
   Zone 3   🔴 존재하지 않는 등급
```

**문제 두 가지**

| # | 문제 |
|---|---|
| 🔴 1 | "Zone 1 → 2 → 3"은 표준을 아는 심사자에게 **위험도가 낮아지는 순서 + 없는 등급**으로 읽힌다 |
| 🔴 2 | **"Zone 1 을 순찰한다" = "이 로봇은 Zone 1 인증 기기다"** 라는 주장이 된다. HazardBot 은 브러시 모터·LiPo·ESP32 를 노출한 구조이고, §2.2 의 복귀 논리 자체가 **「로봇이 점화원 후보」** 를 전제한다 — **자기 모순이다** |

### 6.2 🔵 실제 순찰 운용 단위는 점검점이다

| 제도·사례 | 단위 | 운용 |
|---|---|---|
| **LDAR** (EPA Method 21 / 국내 비산배출 저감제도) | TAG 부여된 **점검 지점** | 사업장 하나에 수천 지점, **전부 같은 절차**. 지점 ID 는 기록용이고 판정을 바꾸지 않는다 |
| 가스누출감지경보기 (KGS·안전보건규칙) | 감지기 **설치 지점** | 가스 비중·누출원 위치로 선정 |
| 4족·AMR 순찰 로봇 | **waypoint + 점검 태그** | 경로 위 각 지점에 "여기서 무엇을 볼지"가 붙는다 |

🔵 **정본 §0-5 「판정은 구역을 몰라야 한다」와 같은 구조다.** 설계는 처음부터 맞았고, 어긋나 있던 것은 이름뿐이었다.

### 6.3 무엇이 실제로 바뀌는가 — 거의 없다

| 대상 | 변경 |
|---|---|
| 물리 배치 | 🔵 **없음** — 코스·격리함·정지마커 그대로 |
| `ZoneId.ZONE1~3` | 🔵 **없음** — 물리 위치 식별자로 이미 격리돼 있다 (정본 §2.1) |
| 통신 프로토콜 | 🔵 **없음** — `<SENS>` 에 구역 필드가 원래 없다 (정본 §5.3) |
| 판정 로직 | 🔵 **없음** — 원래 구역을 보지 않는다 (정본 §3.1) |
| 🟠 **자막 · 나레이션 · PPT · 대시보드** | **"Zone 1/2/3", "구역 A/B/C" → "점검점 P1~P4"** |

🔵 **비용이 자막 수준인데, 심사에서 찔릴 지점 하나가 통째로 사라진다.**

### 6.4 소구획은 Zone 문제를 재발시키지 않는다 — 오히려 점검점을 정당화한다

`시연장_배치` §2.2 의 소구획(점검점마다 ㄷ자 한 쌍)은 **구획**이지 Zone 이 아니다.

| 개념 | 무엇인가 |
|---|---|
| **Zone** (IEC 60079) | 🔴 무엇을 **들여놓을 수 있나** — 기기 자격 |
| **방화구획**(건축법·소방시설법) · **방류벽·방지턱**(화학물질관리법) · **방유제**(위험물안전관리법) | 🔵 무엇이 **새어나가지 못하게 하나** — 화재·누출 방호 |

구획은 로봇에 대해 아무 주장도 하지 않는다. 개구부가 있는 것도 맞다 — 실제 위험물 구획은 밀폐가 아니라 **환기가 요구**된다.

🔵 **§6.2 의 「점검점」 개념을 물리적으로 완성한다.** LDAR 에서 점검 지점이 특정 위치에 있는 이유는 거기에 **잠재적 누출원**이 있기 때문이고, 우리 세트에서는 **셀이 곧 그 자리**다. 「구획이 있으니 점검한다」가 화면에 그려지므로 정지 위치가 임의로 보이지 않는다.

**적색과 황색을 떨어뜨리는 데도 법적 근거가 붙는다** — 유별이 다른 위험물은 원칙적으로 같은 저장소에 둘 수 없다(위험물안전관리법). 적색은 제4류 인화성 액체, 황색은 산화성·자기반응성 계열이다.

🔴 **P4(캔들)와 스테이션에는 구획을 두지 않는다.** 발화원은 보관물이 아니다. **구획이 없다는 사실 자체가 P4 를 「통로에 있으면 안 되는 것」으로 만든다** — 자막 없이 §1.3 의 인과가 읽힌다.

🔴 **구획에 방폭 표지(Ex 육각형)·GHS 그림문자를 붙이지 않는다.** 구획 자체는 주장을 하지 않지만 표지는 한다. **형태가 설명하게 둔다.**

## §7. 파지 2회 유지 — 검토했으나 채택하지 않은 안 〔신규 2026-08-09〕

> 검토 질문: **"파지를 1회만 해도 시나리오가 성립하는가?"** → **성립하지 않는다. 2회 유지.**

### 7.1 🔴 두 파지가 증명하는 것이 다르다

각 주장의 **유일한 증인**이 누구인지 보면 답이 나온다.

| # | 주장 | 증인 | 중복? |
|---|---|---|---|
| 1 | 색만 보는 필터가 아니다 (센서 융합) | P1 통과 + P2 격리 **쌍** | — |
| 2 | **색이 판정 절차 자체를 바꾼다** (황색은 가스를 조회조차 안 한다) | 🔴 **P3(황색) 단독** | 없음 |
| 3 | **파지가 프리셋 재생이 아니다** (2물체 1정책) | 🔴 **P3 파지 단독** | 없음 |
| 4 | 파지·격리 실행 능력 | P2 | 🔵 **P3 와 중복** |
| 5 | 화재 대피 | P4 | — |

**중복되는 것은 4번 하나뿐이고, 그것은 어느 쪽을 빼도 남는다.** 문제는 2·3번이 황색 파지와 함께 죽는다는 것이다.

**2번이 죽으면 판정이 1변수로 붕괴한다.** 남는 규칙이 「적색 + 가스 없음 → 통과 / 적색 + 가스 있음 → 격리」뿐이라 **모든 물체가 적색이므로 색이 판정에 아무 영향도 주지 않는다.** 로봇이 「바퀴 달린 가스 경보기」로 축소된다. 음성 사례를 넣어 "컬러 필터와 구분 불가"를 피했는데, 이번엔 반대쪽에서 **"가스 센서와 구분 불가"** 가 된다.

**3번이 죽으면 ACT 를 쓴 이유가 영상에서 사라진다.** 고정된 정지 위치에서 물체 하나를 한 번 집는 장면은 **프리셋 재생과 화면상 구분되지 않는다.** 정본 §6.4 의 원칙 그대로다 — **"보이지 않는 기능은 없는 기능이다."**

### 7.2 시간이 이유라면 — 계산이 반박한다

| | 초 |
|---|---|
| 현재 실속 합계 | 169 |
| 배속 대상 (구간 주행 + 복귀, 보수적) | 약 65 |
| **2배속 적용 시 절감** | **약 33** |
| 3배속 적용 시 절감 | 약 43 |
| **황색 조우를 통째로 삭제 시 절감** | **40** |

🔵 **이미 확정된 배속(정본 §7.3)만으로 파지 하나를 빼는 것과 같은 시간이 나온다.** 배속은 주장을 하나도 잃지 않고, 파지 삭제는 주장 두 개를 잃는다.

배속 2배 적용 후 합계 약 136초 → **여유 44초 = 재시도 약 3회분.** §7.2 의 "재시도 1회면 예산 초과"는 배속 전 기준이었다.

### 7.3 실패 확률이 이유라면 — 그것도 이미 해결돼 있다

| | 한 테이크 성공률 (p=0.8) | 깨끗한 테이크까지 평균 촬영 |
|---|---|---|
| 파지 2회 | 0.64 | 1.6회 |
| 파지 1회 | 0.80 | 1.25회 |

**차이가 0.35회다.** 정본 §7.5 의 반복 촬영(`/mission/start` 재발행, 노드 재시작 불필요)으로 흡수된다.

### 7.4 🔵 줄일 곳은 파지 횟수가 아니라 물체 난이도다

종이컵은 `시연장_배치` §6.3 비교표에서 **모든 행이 불리하다.** 그런데 「변형체라서 ACT」는 §6.4 에서 이미 기각된 논리라 **컵의 난이도는 비용만 있고 주장으로 회수되지 않는다.**

🟠 **대안 — 노란색 PLA 원뿔대(출력물)로 교체**

| | 유지되는 것 | 얻는 것 |
|---|---|---|
| 색 차이 · 형상 차이(원기둥 vs 원뿔대) · 1정책 2물체 주장 | 🔵 전부 유지 | 강체·하드스톱 확보 · 부하 임계 단일화 · 재사용 가능 · 무게추 불필요 · 폼 패드가 필수→선택으로 하강 |

🔴 **수집 전 작업이므로 하려면 출력 시간을 포함해 수집 개시 전에 결정해야 한다.** 지금 결정하지 않으면 자동으로 종이컵 유지다.
