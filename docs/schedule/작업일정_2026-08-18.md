# 🔴 오늘의 갈림길 — NoIR 색 분리 (오전 중 결론)

**감지 카메라가 CSI NoIR 임이 8/16 에 판명됐다.** IR 차단 필터가 없어 **노랑이 적색 쪽으로 밀린다.**
정본 §3.1 **판정표 4행 중 3행이 색으로 갈린다** — 여기가 안 서면 시나리오가 서지 않는다.

### 판정 방법

- 🔴 **카메라 2대에서 각각 잰다** — CSI NoIR(감지) · 손목 SO-ARM(ACT 입력, 정색)
- 🔴 **오늘 고정한 촬영 조명 아래에서** 잰다. 다른 조명에서 잰 값은 의미가 없다
- 적색 소분 용기(P1·P2) · 노란 종이컵(P3) 을 **각각의 소구획 안에 놓은 상태로** — 근경 배경이 셀이다
- 판정 기준: **Hue 분포가 겹치지 않는가.** 겹치면 S·V 로 갈리는가

### 실패하면 — 대책 순서를 지킨다 (`시연장_배치` §7.3-③)

```
  ① 조명 LED 고정      ← 오늘 어차피 한다
  ② AWB 고정
  ③ IR-cut 필터
  ④ 형상 특징 병용 (색 단독 → 색 + 형상)
  ⑤ 보유 중인 Innomaker 로 교체     ← 신규 구매는 마지막
```

🔴 **오전 중에 결론을 낸다.** 오후까지 끌면 수집이 내일로 안 넘어간다.
③~⑤ 로 가야 하면 **그 자체가 오늘의 우선순위**가 되고, 수집은 8/20 으로 하루 민다.

# 3단계 — 수집 전 게이트 ①~⑤ (승환)

`시나리오_확정_보완_2026-08-16.md` §8.2. **⓪ 는 세트 완료로 닫혔다. ①부터가 오늘이다.**

### ① 그리퍼 골무 부착
- 목적은 완충이 아니라 **파지력** — 테이퍼 쐐기 미끄러짐을 잡는다 (무게추는 8/16 에 삭제됨)
- 🔴 **그리퍼 최대 개구 실측을 골무 낀 상태로** 한다
- 🔴 **수집 전에 끼운다.** 나중에 끼우면 두께만큼 개구가 줄어 **적색 데이터까지 무효**

### ② 차체 통과 10/10 · 그리퍼 진입
- 소구획이 **관통형**이라 기준이 그리퍼가 아니라 **차체**다 (🟠 개구부 400mm 내외)
- 🔴 **10회 중 10회 통과.** 걸리면 개구부를 넓힌다
- 셀 안에서 **그리퍼가 물체에 닿는가** — 막히면 수집한 데이터가 통째로 무의미해진다

### ②-1 격리함 뚜껑 3항목

| | 확인 | 못 지키면 |
|---|---|---|
| 높이 | 물체가 **어떤 자세로 앉아도 뚜껑 아래** | 뚜껑이 걸린다 = **봉쇄 실패**. 파지 실패보다 나쁘다 |
| 경로 | **열린 뚜껑이 투입 동선을 막지 않는다** | 넣는 동작이 뚜껑에 걸린다 |
| 각도 | **백스톱으로 열림 각도가 매번 같다** | 접촉 지점이 흔들려 재현이 안 된다 |

### ③ 캘리브레이션 재조정 (화각 좌측 편향)
- ⚠ **먼저 확인** — 치우침의 원인이 **카메라 브래킷이 돌아간 것**이라면 브래킷을 돌리는 편이 싸다
- 🔴 **연쇄가 따라온다** — `check_home.py` 기준 재저장 → `wrist_roll` 안전 범위 재설정
- 🔴 **캘리브레이션 프롬프트에서 `c` 금지.** 엔터만 (구축기록 §5-1 · §5-2 재발)
- 🔴 **수집 후에 바꾸면 데이터 전량 무효**

### ⑤ 정지 산포 ×10
- 정지점 1·2 에서 각 10회, 🔴 **θ(yaw) 우선**
- 수집 범위를 정하는 값이다 — 산포를 모르면 **어디까지 놓아도 되는지를 모른 채 수집**하게 된다

- **리더암 서보는 7.4V.** 12V 를 물리면 6개 전멸 (₩178,315, 복구 불가). XL4015 `#A` 전용
