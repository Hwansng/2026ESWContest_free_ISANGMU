## 4. 성공 에피소드 정의

한 에피소드에는 다음 동작만 포함한다.

1. 팔로워암이 고정 홈 자세에서 시작한다.
2. 지정된 색상의 물체 한 개만 지정 위치에 둔다.
3. 격리함은 비어 있고 뚜껑은 완전히 열린 상태로 둔다.
4. 물체에 접근한다.
5. 물체를 한 번에 안정적으로 잡는다.
6. 충돌이나 낙하 없이 격리함으로 운반한다.
7. 물체를 격리함 안에 놓고 그리퍼를 해제한다.
8. 격리함 뚜껑을 완전히 닫는다.
9. 닫힌 상태를 1초 유지한 뒤 종료한다.

팔을 홈으로 되돌리는 과정, 물체 회수, 뚜껑을 다시 여는 과정은 녹화하지 않는다.

다음 중 하나라도 발생하면 실패 에피소드로 처리한다.

- 첫 시도에 잡지 못함
- 물체를 놓침
- 로봇이나 물체가 주변과 충돌함
- 물체가 격리함 밖에 놓임
- 뚜껑이 완전히 닫히지 않음
- 1초 이상 불필요하게 멈춤
- 불필요한 왕복이나 되돌리기 발생
- 중간에 동작을 수정함
- 35초 초과

조작 키는 LeRobot 0.6.1 기준으로 다음과 같다.

- `N` 또는 `→`: 성공 저장 및 다음 단계
- `R` 또는 `←`: 현재 버퍼 폐기 후 같은 에피소드 재촬영
- `Q` 또는 `Esc`: 전체 녹화 종료
- `Ctrl+C`: 통신 이상 또는 물리적 위험이 있을 때만 비상 종료

## 7. 실제 수집 시도와 실패 과정

### 7.1 첫 번째 실행 실패

`record_act.ps1`에서 화면 표시 옵션을 다음과 같이 잘못 전달했다.

```text
--dataset.display_data=true
```

LeRobot 0.6.1에서는 이 옵션이 데이터셋 하위가 아니라 최상위 옵션이므로 다음과 같이 수정했다.

```text
--display_data=true
```

이 실패에서는 녹화가 시작되지 않았고 에피소드도 저장되지 않았다.

### 7.2 두 번째 실행 실패

신규 데이터셋을 시작하기 직전에 PowerShell 스크립트가 데이터셋 폴더를 미리 생성했다. LeRobot의 신규 생성 로직은 대상 폴더가 없어야 하므로 다음 오류가 발생했다.

```text
FileExistsError: [WinError 183]
output\act_red_yellow_v1
```

확인 결과 해당 폴더는 완전히 비어 있었으며, 빈 폴더만 제거했다. 이후 `record_act.ps1`에서 `New-Item` 사전 생성 코드를 제거해 LeRobot이 직접 폴더를 만들도록 수정했다.

### 7.3 세 번째 실행

세 번째 실행에서는 다음 단계까지 진입했다.

```text
leader_arm SOLeader connected.
OpenCVCamera(1) connected.
follower_arm SOFollower connected.
Keyboard listener started.
Recording episode 0
```

하지만 실제 팔로워암은 리더암을 따라 움직이지 않았다. 따라서 정상적인 텔레옵 궤적은 만들어지지 않았다.

에피소드 0의 35초 구간이 종료된 뒤 왼쪽, 오른쪽, Esc 입력이 감지됐다. 재촬영과 종료 이벤트가 겹친 뒤 키보드 이벤트가 반복해서 들어오는 비정상 상태가 됐다. 정상 종료를 기다리고 `Ctrl+C`를 두 번 보냈지만 Python 프로세스가 종료되지 않았다.

최종적으로 녹화 Python 프로세스 PID 6748만 강제 종료했다. 통합 실행 세션은 종료 코드 1로 끝났다.

## 14. 다음 작업 시작 전 필수 진단

다음 세션에서는 데이터 수집을 바로 시작하지 말고 팔로워암 텔레옵 문제부터 해결해야 한다.

권장 순서:

1. 팔로워암 전원이 꺼져 있는지 확인한다.
2. 작업공간에서 이전 녹화 Python 프로세스가 남아 있지 않은지 확인한다.
3. 리더 COM6, 팔로워 COM7이 그대로인지 장치 관리자에서 확인한다.
4. 팔 주변을 비운다.
5. 팔로워암만 읽기 전용 점검한다.
6. 양팔 Present Position 정렬을 확인한다.
7. Goal Position을 Present Position으로 동기화한다.
8. 데이터 저장 없이 짧은 텔레옵을 실행한다.
9. 팔로워암이 리더암의 여섯 축을 실제로 따라 움직이는지 사람이 확인한다.
10. 텔레옵을 정상 종료하고 토크가 해제되는지 확인한다.
11. 별도 pilot 데이터셋에서 성공 에피소드 1개만 기록한다.
12. 영상·관절 데이터·액션·프레임 수를 전체 검사한다.
13. pilot이 정상일 때만 불완전한 production 폴더 처리 방법을 결정하고 배치 1을 시작한다.

연결 메시지만 보고 9번을 생략하면 안 된다.

## 15. 다음 세션에서 사용할 명령 예시

아래 명령은 참고용이며, 팔 주변 안전과 포트를 확인한 뒤 실행해야 한다.

## 16. 안전 인계 사항

- 오늘 성공 데이터는 0개다.
