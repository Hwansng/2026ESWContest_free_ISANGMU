## 0. 먼저 확인한 것 — 커밋에 RETURN이 없다

`jinu-rpi5-restore`(`19fe096`)의 `mission_orchestrator_node.py`를 다시 grep 해봤는데 `RETURN`·`return_request`·`return_done` 전부 **한 건도 없음**. `MissionState`엔 `IDLE/PATROL/DETECTED/CLASSIFY/APPROACH/GRIP/TRANSPORT/ISOLATE/REPORT/EMERGENCY/HOME`뿐이고, `hazard_cb`의 `FLAME`은 지금 그대로 `EMERGENCY`로 감(153번줄 근처, `if data.get('type') == 'FLAME': self.transition(MissionState.EMERGENCY)`).

즉 저번에 보내주신 mock 테스트 스크립트("화염 → RETURN → 후진 요청 → RETDONE → IDLE")는 **설계안**이고, 실제 커밋엔 아직 없는 상태였음. 그래서 mock을 그대로 돌리면 `FSM: PATROL → RETURN`이 안 뜨고 `EMERGENCY`가 뜰 거임 — 아래 패치 적용 후 다시 돌리면 맞게 나올 것.

## 1. DRIVE 쪽 — 완료

`esp32_drive_tcp.ino`에 넣은 것:

- **`<DETECT,CS>` 송신** — `onMarker()`에서 정지 마커 도달마다 1회. 구역 구분 안 하고 모든 정지점에서 보냄(stopIndex↔ZONE 매핑이 아직 어디에도 없어서, 물체 없는 지점이면 vision_node가 "감지 없음"으로 넘어갈 뿐이라 무해함)
- **`<RETURN,CS>` 수신** — 받으면 즉시 개루프 후진 시작. ESTOP은 안 건드림(이미 래치돼 있으면 `motionBlocked()`가 그대로 막음)
- **`<RETDONE,CS>` 송신** — 후진 타이머 끝나면 1회. `motionBlocked()`로 중단된 경우엔 안 보냄(STOP/EMERGENCY 경로가 따로 있어서)
- 🟠 **`RETURN_DURATION_MS=1500`, `RETURN_SPEED=100`는 실측 전 잠정값.** 오도메트리가 없어서 개루프(시간×속도)뿐이고, "800mm"는 8/25 이월 목록의 목표치일 뿐 확정 아님. 시리얼 `r`(강제 후진, STBY 켠 상태에서만) / `R`(+200ms)로 벤치에서 자로 재서 맞춰야 함
- `dist`는 이제 `object_near` 판단에 안 씀(DETECT가 대체) — RPi가 dist 기준으로 임계 비교할 필요 없어짐, DRIVE가 알아서 판단

## 2. RPi 쪽 — 패치 초안 (그대로 옮기면 됨)

### 2.1 `amr_bridge_node.py`

**① `last_recv_time` 갱신 — 지난 확인요청 문서의 1번, 이것부터 안 되면 나머지 전부 무의미**

`parse_msg` 맨 위에 한 줄 추가(sensor_bridge와 동일 패턴):

```python
def parse_msg(self, line: str):
    self.last_recv_time = time.time()   # ← 추가
    if not (line.startswith('<') and line.endswith('>')):
        ...
```

**② `DETECT`/`RETDONE` 수신 처리 + `RETURN` 송신 경로**

`__init__`에 publisher/subscriber 추가:

```python
self.pub_return_done = self.create_publisher(String, '/amr/return_done', 10)
...
self.create_subscription(String, '/amr/return_request', self.return_request_cb, 10)
```

`parse_msg`의 `if cmd == 'SENS' ...: ... else: ...` 사이에 분기 추가:

```python
        elif cmd == 'DETECT':
            self.pub_near.publish(Bool(data=True))
            self.get_logger().info('DETECT 수신 — /amr/object_near=True 발행')

        elif cmd == 'RETDONE':
            self.pub_return_done.publish(String(data='done'))
            self.get_logger().info('RETDONE 수신 — /amr/return_done 발행')

        else:
            self.get_logger().debug(f'알 수 없는 CMD: {cmd}')
```

새 콜백 추가:

```python
def return_request_cb(self, msg: String):
    self.get_logger().warn(f'/amr/return_request 수신: {msg.data} — RETURN 프레임 전송')
    self.build_and_send('RETURN')
```

### 2.2 `mission_orchestrator_node.py`

**① `MissionState`에 `RETURN` 추가**

```python
class MissionState:
    ...
    EMERGENCY  = 'EMERGENCY'
    RETURN     = 'RETURN'      # ← 추가
    HOME       = 'HOME'
```

**② publisher/subscriber 추가**

```python
self.pub_return_request = self.create_publisher(String, '/amr/return_request', 10)
...
self.create_subscription(String, '/amr/return_done', self.return_done_cb, 10)
```

**③ `hazard_cb`에서 FLAME을 EMERGENCY 대신 RETURN으로**

```python
def hazard_cb(self, msg: String):
    data = json.loads(msg.data)
    level = data.get('level', 0)

    if data.get('type') == 'FLAME':
        self.transition(MissionState.RETURN)   # ← EMERGENCY 대신
        return

    if level >= 2 and self.state == MissionState.PATROL:
        self.transition(MissionState.DETECTED)
```

**④ `transition()`에 RETURN 진입 처리 추가**

```python
elif new_state == MissionState.RETURN:
    self.set_led('2')
    self.set_buzzer('1')
    msg = String()
    msg.data = json.dumps({'reason': 'FLAME'})
    self.pub_return_request.publish(msg)
    self.get_logger().error('화염 감지 — RETURN 요청 전송')
```

**⑤ RETDONE 확인 콜백**

```python
def return_done_cb(self, msg: String):
    if self.state != MissionState.RETURN:
        return
    self.get_logger().info('RETURN 완료 확인 — IDLE 복귀')
    self.transition(MissionState.IDLE)
```

🔲 **결정 필요 — 진우 님 판단대로 가도 됨.** RETURN→IDLE을 EMERGENCY→PATROL처럼 사람 확인(`reset_cb`의 `SAFE_TO_RESUME`) 없이 자동으로 뒀음(진우 님 mock 스크립트 그대로 따름). 화염이라는 심각한 위험을 자동 복귀시키는 게 맞는지는 재고 여지 있음 — RPi 쪽 판단이라 여기서 정하지 않았음.
