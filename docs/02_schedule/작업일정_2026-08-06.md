# 1단계 — 🔴 촬영 조명 확정 (다른 무엇보다 먼저)

오늘 하는 측정 **3개가 전부 조명에 종속**된다.

```
촬영 조명  ─┬─  라인센서 감도
            ├─  HSV 임계값
            └─  정지 산포
```

조명을 나중에 바꾸면 셋 다 다시 잰다.

### 🔴 재현 가능하게 남길 것

세트는 언젠가 철거한다. 재현이 안 되면 **「수집과 촬영이 같은 조명」** 이라는 전제가 깨진다.

- [ ] 조명·삼각대 **발 위치를 바닥에 테이프로 마킹**
- [ ] **밝기·색온도 설정값을 사진으로 기록**
- [ ] 세트 기준선(벽체 모서리·코스 시작점)도 같이 마킹

# 2단계 — 셋으로 갈라져 병렬 (오전)

> **먼저 5분: 파지물 확정.** 적색 강체 · 황색 종이컵을 셋이 함께 고르고 흩어진다.
> 진우 작업이 여기서 시작되므로 이것부터 한다.

| | 승환 | 강희 | 진우 |
|---|---|---|---|
| **작업** | 라인 테이프 **폭 시험** (짧은 구간) | **벽체 제작·설치** | **파지물 HSV·형상 측정** |
| **산출** | 폭 확정 → 본 코스 부설 가능 | 구역 경계 확정 | 🔴 **정색 웹캠 발주 여부** |

### 진우 측정 항목

- **실물 HSV** — 🔴 **노랑 S 값이 오르는지가 핵심**
  1차 테스트는 `노랑 S 19~58`. 그 구간에서는 색상(H)이 사실상 노이즈라
  「H 겹침 0.00 = 분리됨」 판정을 믿을 수 없다

  | 결과 | 판단 |
  |---|---|
  | S 가 오른다 | 테스트 물체가 옅었던 것 → 정색 웹캠 **불필요 확정** |
  | S 그대로 | 🔴 **NoIR 탈색** → **오늘 웹캠 발주** |

- **형상 특징값** (면적·채움률·원형도) — 실물이 있어야만 가능
- **조명 아래에서 다시** — 최종 임계는 촬영 조명 기준

# 5단계 — 코스 부설 (오후 전반)

```
벽체 완료 → 코스 레이아웃 마킹 → 라인 부설 → 마커 부설 → 소품 가배치
```

- **마커는 정지점 4곳 × 2줄 = 가로선 8줄** (감속 마커 + 정지 마커)
- **감속↔정지 간격 200~300mm** — 제동거리 실측 후 조정
- 우드락 경계 기둥 **받침이 주행로 안으로 들어가지 않게**
- 🔴 **소품은 「가배치」** — 파지물 최종 위치는 정지 산포 실측 이후에 확정한다

### 파지물 배치 규칙 (수집·촬영 동일하게)

- **적색 블록은 정방향** — 어긋남은 위치(x·y)만
- **자로 맞춰 정렬하지 않는다** — 손으로 놓을 때 나는 자연 오차를 그대로 둔다
- 마커 정중앙에 반듯하게 놓지 않는다
- 두 파지 대상을 한 화면에 두지 않는다

# 6단계 — 라인트레이싱 (오후 중반)

**순서가 정해져 있다.** 분기를 먼저 붙이면 무엇 때문에 흔들리는지 구분이 안 된다.

```
1. 분기 없이 전 구간 안정화        ← 먼저
2. 그다음 분기 붙이기
3. KEEP_INNER / KEEP_OUTER 각 10회
4. 코너 ToF 최소 벽거리 실측
```

---

# 7단계 — 섀시 (플레이트가 나온 경우)

```
섀시 조립 → 마운트 고정 → 팔 장착
```

**여기까지만 해도 오늘은 성공이다.**

> 🔴 **캘리브레이션 동결은 되돌릴 수 없다.**
> 수집 후에 바꾸면 데이터셋 전량 무효 + **31시간 재학습**이고, 재학습 기회는 사실상 한 번이다.
> **마운트가 최종이라고 확신할 때만** 넘어간다. 급하게 동결하는 것이 오늘 나올 수 있는 최악의 결과다.

---

# 8단계 — 정지 산포 실측 (시간이 남으면)

**팔이 장착된 상태여야 한다** — 무게가 제동거리를 바꾼다.

### 측정 조건

- 라인센서 감도를 **실제 주행 높이 · 촬영 조명**에서 최종 조절한 다음
- 출발점을 매번 동일하게 (접근 구간 길이가 다르면 속도가 다르다)
- 차체 기준점을 하나 정하고 **매번 같은 점**으로 잰다

### 측정

정지점 1·2에서 각 **10회**, 매회 **x · y · θ** 기록.

| 기호 | 측정값 |
|---|---|
| **x** | 진행 방향 전후 오차 (mm) |
| **y** | 좌우 오차 (mm) |
| **θ** | 차체 방위각 (도) |

- 🔴 **정지점 1(적색)의 θ 를 우선** — 정방향 배치라 θ 흡수 여유가 좁다. 3° 초과 시 조치 필요
- 각각 **최댓값 − 최솟값**을 산포로 기록하고, ③ 으로 넘길 때 **여유 30% 를 더한다**

> 완전한 측정은 배터리 **완충/중간/하한 3구간 × 2정지점 × 10회 = 60주행**이다.
> **오늘은 완충 구간만** 끝내도 충분하다.
