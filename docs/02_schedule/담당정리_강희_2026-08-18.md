### 🔴 전력이 넘어가도 강희에게 남는 것

**납땜하는 사람이 강희이므로, 전력 「결정」은 승환이 해도 「구현」은 강희 손에서 나온다.**

| | 결정 | 구현 |
|---|---|---|
| MQ 5V 급전점 | 승환 (전력) | **강희 (납땜)** |
| 분압 저항값 | 배선 정본 §1.3 | **강희 (납땜)** |

🔴 **그래서 §2(MQ 급전점)를 강희가 계속 읽어야 한다.** 인두를 든 사람이 마지막 관문이다.
🔴 **배선 정본과 다르게 붙일 상황이 오면 혼자 정하지 말고 승환에게 넘긴다.**

### 보드 호칭

🔴 **`DRIVE` / `ENV` 로 통일한다.** 번호(#1/#2)는 문서마다 가리키는 보드가 달라 **사고 이력이 있다**(8/1).
🔴 **납땜 설명서 PDF 2쪽이 두 기판을 모두 "ESP32 #1" 로 적고 있다.**
손에 인두를 들고 보는 문서이므로 반드시 고칠 것.

### ENV 가 하지 않는 일

- 🔴 **판정하지 않는다** — 원시값·이동평균만 보낸다. 임계 분기는 RPi 가 한다
- 🔴 **정지 권한이 없다** — 모터를 멈추는 것은 **DRIVE 뿐**이다. ENV 도 RPi 도 「요청」만 한다
- **VL53L1X 는 DRIVE 담당**(7/30 확정) · **배터리 분압도 DRIVE**(G39) · **WS2812B 미사용**

> *판정하지 않는 보드가 정지 권한을 가질 수는 없다* — 두 결정이 일관된다 (v5 §5.3.1).

| 2 | `<BUZZ,n>` 수신 → **G26** 능동 부저 구동 | 소 | 화재·복귀 경보 |
| 3 | `<SENS>` 필드 정리 — `DISTANCE` · `BAT` **제거** | 소 | 둘 다 DRIVE 소관 |
| 4 | 🔴 **화염(KY-026 G27, LOW 액티브) 필드 확실히 채울 것** | 소 | 🔴 **시나리오 12번(화염 → 후진 이탈) 전체** |

## 1.1 포트 — 오늘 합의에서 확정

| | 값 |
|---|---|
| 코드 | **8765** |
| 문서 | **5002** |

🔴 **둘 중 하나로 통일한다.** 진우의 `sensor_bridge_node.py` 와 **같은 값**이어야 한다.
성공 기준은 낮게 잡는다 — **가스값 하나가 대시보드에 뜨면 오늘은 성공이다.**

## 1.2 `<BUZZ,n>` — 형식을 오늘 확정

- 🔲 **`<BUZZ,1>` 로 확정 필요** (진우와 인터페이스 합의 항목)
- 부저는 **3핀 능동 모듈 직결**, **G26**, VCC 는 **3V3**
- 🔵 부저 + 대시보드의 **이중 채널**이 「현장 경보 + 관제 보고」라는 산업 서사를 완성한다

## 1.3 🔴 KY-026 — LOW 액티브

```
  화염 감지 시  →  DO = LOW
```

🔴 **부호를 뒤집어 읽으면 「불이 없을 때 경보」가 된다.** 시나리오의 마지막 장면이 여기서 갈린다.

**동작 순서** — 감지 → 정지 → 부저 → **후진** → 정지.
🔵 「충전 스테이션 복귀」가 아니라 **「점화원 이탈 · 관제 보고」**다 (8/9 변경).

## 1.4 ENV 핀 배정 (배선 정본 §1.2)

| 센서 | 신호 | 핀 | 비고 |
|---|---|---|---|
| MQ-135 | AO → 분압 | **G34** | 입력 전용 · ADC1_CH6 |
| MQ-2 | AO → 분압 | **G35** | 입력 전용 · ADC1_CH7 |
| KY-026 | DO | **G27** | 🔴 **LOW active** |
| 능동 부저 | I/O | **G26** | 3핀 모듈 직결 |

🔴 **DRIVE 와 핀 번호가 겹쳐도 무관하다 — 다른 칩이다.**
G26(ENV 부저 / DRIVE AIN1) · G27(ENV KY-026 / DRIVE AIN2) · G35(ENV MQ-2)는 서로 관계없다.

# 2. ⚠ MQ 5V 급전점 — 실배선이 정본과 다르다 〔납땜 중 확인〕

**현재 MQ 센서가 ESP_Env 의 5V/VIN 에서 급전되고 있다.**
배선 정본 §0-④ 는 🔴 **XL4015 #B 출력에서 별도 한 쌍**이다.

🔵 **전력 계통 자체는 승환 담당이 됐지만**〔8/18〕, **급전선을 실제로 붙이는 것은 납땜하는 강희다.**
🔴 **지금 만능기판을 뜨고 있으므로 지금이 고칠 수 있는 마지막 시점**이다 — 완성 후에는 되돌리기 어렵다.

## 왜 정본이 그렇게 정했는가

| # | 이유 |
|---|---|
| ① | MQ 히터 합산 **상시 ~330mA** (135:150 + 2:180). ESP32 VIN 경유 시 USB 시험에서 250+330 = **580mA** 가 devkit 폴리퓨즈(통상 500mA)와 노트북 USB 포트를 통과한다 → **브라운아웃·리셋** |
| ② | 히터 리턴이 ADC GND 와 같은 레일이면 **MQ 를 읽는 그 자리에 히터 전류가 그라운드 바운스를 얹는다** — 가스값이 흔들린다 |

> `만능기판_이전_가이드.md` §4.5 원문:
> *"ENV 보드는 XL4015 **출력 단자에서 별도 한 쌍**을 뽑는다. **데이지체인 금지** —
> MQ 히터 상시 300mA 가 DRIVE 쪽 5V 를 흔든다."*

🔴 **`GAS_THRESHOLD` 를 재기 전에 정리한다.** 급전점이 바뀌면 가스값 기준선이 바뀌어
**오늘 잰 임계값이 무효**가 된다.

## 전원 레일 (배선 정본 §1.1)

| 레일 | 공급원 | 부하 |
|---|---|---|
| **5V_SENSOR** | 🔴 **XL4015 #B 출력에서 별도 한 쌍** | MQ-135 VCC, MQ-2 VCC **만** |
| **3V3** | ESP32 3V3 | KY-026 VCC, 부저 VCC |
| **ADC GND** | ESP32 GND | 센서 GND, 분압 하단저항, 부저 GND |
| **히터 GND** | 🔴 **벅 GND 직결** | MQ 히터 리턴 — ADC GND 와는 **스타포인트에서만** 만난다 |

**MQ 분압은 10k / 10k = 2.50V** (10k/20k 는 3.33V 로 **ADC 상단 포화 — 금지**).

# 3. 🔵 오늘 열린 실측 — 세트가 있어야 되던 것들

**「세트 제작 후」로 대기하던 항목이 전부 가능해졌다. 오늘 안 재면 수집·촬영 당일로 밀린다.**

## 3.1 🔴 `GAS_THRESHOLD` 실측 (정본 §9-4)

**음성/양성 사례를 가르는 값이다.** 시나리오에서 가장 정교한 장면이 여기 걸린다.

| 지점 | 물체 | 가스 | 판정 |
|---|---|---|---|
| **P1** | 적색 소분 용기 (향 **없음**) | 없음 | 🔵 **통과** |
| **P2** | 적색 소분 용기 (향 **있음**) | 있음 | 위험 → 격리 |
| **P3** | 노란 종이컵 | 무관 | 위험 → 격리 |

🔴 **P1 을 통과시키는 장면이 없으면 이 로봇은 컬러 필터와 구분되지 않는다.**

**측정 조건**
- 🔴 **오늘 고정한 촬영 조명 아래에서** · 🔴 **MQ 급전점을 정리한 뒤에**
- 예열 완료 상태에서 (예열은 촬영 **전**에 끝낸다 — 시간 예산에서 제외)
- 기준선(향 없음)과 검출값(향 있음)을 **각각 여러 번** 재고, 그 사이에 임계를 둔다

## 3.2 🔵 P3 도착 시 가스 회복 (정본 §9-12)

**MQ-2 회복이 ~30초**다. P2 에서 향을 맡은 뒤 P3 에 도착했을 때 **수치가 정상으로 돌아와 있어야**
*"가스가 없는데 집는다"*(= 황색은 가스와 무관하게 위험)가 화면에서 성립한다.

- 안 떨어지면 → **P2·P3 간격을 늘리거나 향의 양을 줄인다**
- 🔴 **P1 → P2 순서 고정** (P1 이 먼저 와야 기준선이 깨끗하다)

## 3.3 KY-026 감도 — 촬영 조명 아래에서

- 🔴 **백열·할로겐 조명에 오검출**한다. KY-026 은 **760~1100nm** 를 본다
- 🔵 **LED 조명이 이 문제와 NoIR 색 밀림을 동시에 줄인다** — 조명 선택 하나로 두 문제가 준다
- 캔들(실화염)에는 확실히 트리거되고, **깜빡임까지 실제 화재 감지기가 보는 신호와 같다**

## 3.4 ToF 장착 높이 + 300mm 임계 (승환과)

- 🔴 **소구획을 세운 상태에서** 잰다 — 셀 벽이 들어오면 오검출로 멈춘다
- 걸리면 **ROI 축소 → 임계 하향 → 개구부 확대** 순
- 🔵 임계는 **300mm 단일**로 확정됐다 (구간 전환 로직은 8/18 에 폐기)
