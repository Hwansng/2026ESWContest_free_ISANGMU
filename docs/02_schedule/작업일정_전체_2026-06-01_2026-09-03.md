## 배치 원칙

| 원칙 | 이유 |
|---|---|
| 계획 정본·저장소가 최우선 | 이후 모든 산출물이 들어갈 그릇 |
| 전력 계통 설계 → 서보 통전 | 12V 오인가 사고가 이 순서를 강제로 확인시킨 지점 |
| 캘리브레이션 → 막힌 지점 → 텔레옵 | 정본 값이 없으면 텔레옵 정렬 확인 자체가 불가 |
| 텔레옵(★M1) → DRIVE | 팔이 서야 주행 통합에 의미가 생긴다 |
| 시나리오 정본 → 세트 제작 | ZONE·판정 기준이 세트 치수를 결정한다 |
| 세트 + 조명 확정 → ACT 수집 | 「수집 조명 = 촬영 조명」 원칙. 이후 변경 시 데이터 전량 무효 |
| 수집 게이트 ①~⑤ → 수집 실행 | 순서를 바꾸면 수집 데이터가 무효화된다 |
| 수집 100/100 → 학습 100k | 통짜 실행이라 야간 1회로 잡아야 한다 (계획 당시 15.6h 로 추정 · **실측 4h47m**) |
| 규정 확인 → 분량 → 페이지 구성 → 파일 구성 페이지 | 9/1~9/3 배치 근거. 분량 산정을 모르면 페이지를 못 짜고, 저장소가 확정돼야 「파일 구성」을 채울 수 있다 |
| 승환 설계 → 저장소 구현 | 하트비트는 07/28 설계 → 08/04 구현, 판정매트릭스는 07/28 구현 → 08/20 문구 교체. 설계가 커밋에 선행한다 |
