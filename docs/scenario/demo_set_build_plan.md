## 1. 문서 목적과 적용 범위

이 문서는 HazardBot이 산업현장에서 위험물을 탐지하고 안전하게 처리하는 과정을 촬영·시연하기 위한 축소 세트의 제작 기준을 정한다. 팀원이 이 문서만 보고 재료 구매, 모듈 제작, 현장 조립, 로봇 시험, 촬영 전 검증을 수행할 수 있도록 하는 것이 목적이다.

이 문서는 다음 내용을 다룬다.

- 강의실에 설치할 약 3.6m × 4.0m 규모의 촬영용 세트
- 단프라와 폼보드를 이용한 저비용 벽체 및 산업현장 소품
- 흰색 계열 강의실 바닥을 이용한 검정 라인트레이싱 경로
- 260mm × 260mm 크기의 3층 이동로봇이 이동할 공간
- 위험물 탐지·분류·처리와 화재 대응 장면을 위한 구역 구성
- 산업안전 기준을 참고한 표지와 동선 연출
- 제작물의 전도 방지, 비상 접근, 전기·화재 안전
- 라인 센서, 비전 카메라, 로봇팔 동작을 고려한 검증 절차

다음 내용은 이 문서의 범위 밖이다.

## 2. 시연 세트의 목표

세트는 다음 다섯 가지 목표를 동시에 만족해야 한다.

1. **현장감:** 강의실 배경보다 산업현장 요소가 먼저 보이도록 한다.
2. **저비용:** 완제품 파티션 대신 재단 가능한 단프라와 재활용 보강재를 사용한다.
3. **수정 용이성:** 직접 제작하면서 구역과 소품 위치를 반복 조정할 수 있어야 한다.
4. **로봇 호환성:** 라인 센서, 비전 카메라, 로봇팔의 시야와 동작을 방해하지 않아야 한다.
5. **안전성:** 전면을 개방하고 Emergency Stop과 로봇 전원에 즉시 접근할 수 있어야 한다.

- 별도의 세트 바닥은 제작하지 않는다.
- 강의실의 밝은 바닥을 그대로 사용한다.
- 라인트레이싱은 검정색 무광 테이프로 구성한다.
- 세트 사용 바닥 면적은 약 3.6m × 4.0m로 계획한다.
- 후면 벽은 폭 3.6m, 높이 0.9m로 제작한다.
- 좌우 측벽은 각각 깊이 약 1.2m, 높이 0.9m로 제작한다.
- 카메라와 운영자가 위치하는 전면은 개방한다.
- 전체 네 면을 벽으로 둘러싸지 않는다.
- 생수병이나 외부 무게추로 벽을 지지하지 않는다.
- 벽 뒤쪽의 삼각기둥, 접이식 발, 코너 연결로 자립시킨다.
- 폐박스와 폐골판지는 정면 외장재가 아니라 보이지 않는 내부 보강재로만 사용한다.
- 연기, 가스, 액체 위험물은 사용하지 않는다.

- 적색·황색 바닥 장식은 비전 인식 혼동을 피하기 위해 사용하지 않는다.

> **🔵 점검점이 거기 있는 이유가 화면에 그려져 있다** 〔2026-08-09 신설〕
>
> 실제 현장에서 점검점이 특정 위치에 있는 이유는 **거기에 보관 구획이 있기 때문**이고,
> 구획이 나뉜 이유는 임의가 아니다.
>
> | 근거 | 우리 배치와의 대응 |
> |---|---|
> | **위험물안전관리법 — 유별 혼재·혼합저장 제한** | **적색 = 제4류 인화성 액체 / 황색 = 산화성·자기반응성 계열** → 애초에 같은 칸에 둘 수 없다. **P2 와 P3 를 떨어뜨린 이유가 여기서 나온다** |
> | **화학물질관리법 — 방류벽·방지턱** | ㄷ자 소구획의 **형태 자체가 이것이다** |
> | **LDAR** (EPA Method 21) | 점검 대상은 **잠재적 누출원이 있는 물리적 지점**. 셀 = TAG 가 붙을 자리 |
>
> **가장 강한 효과는 P4 에서, 구획을 두르지 *않기* 때문에 나온다.**
>
> ```
>    구획이 있다  →  보관 지점  →  점검 대상        P1 · P2 · P3
>    구획이 없다  →  통로       →  아무것도 없어야 함
>    ─────────────────────────────────────────────────────────
>    그런데 통로에 불이 켜져 있다                    P4  🔥
> ```
>
> 발화원은 보관물이 아니다. 구획을 두르면 「발화원을 보관하는 칸」이 되어 서사가 무너진다.
> **구획의 유무가 「보관물 / 이물」을 가르는 문법이 된다.**

> 향 없는 소분 용기을 먼저 지나가지 않으면 잔류 가스로 정상품을 위험물로 오판하고,
> **데모의 핵심 장면이 그대로 실패 장면이 된다** (§5.1).

### 4.5 🔴 분기는 하나만 — 그리고 반드시 마커와 함께

선이 만나는 지점은 위험하다. **5채널이 전부 검정**이 되면 정지점 마커와 구분되지 않고,
거기까지 가지 않아도 한쪽에 선이 더 있으면 **조향 가중평균이 쏠려 로봇이 휜다.**

- 8자 경로 ❌
- 가운데를 가로지르는 복귀선 ❌
- **지선 1개 + 분기점 마커 + 분기 선택 로직** ✅ (2026-08-04 확정, §5.4)

충전 스테이션은 루프 밖에 있고 **지선 하나로 루프에 접선 합류**한다.
분기점은 **정지점 4번**이 되며, 순회 중에는 **세되 서지 않는다.**

**분기가 하나뿐이라는 것이 조건이다.** 두 개 이상이면 분기 선택 로직이 어느 분기를
말하는지 관리해야 하고, 그때부터는 마커에 고유 ID 가 필요해진다 — RFID 를 기각한 근거(§3)가
무너지는 지점이므로 **지선은 하나만 둔다.**

위 도면은 구역의 상대적 위치만 나타낸다. 실제 위험물 처리 위치, 로봇팔 작업대, 출발점은
라인트레이싱과 비전 시험 후 바닥에 표시한다.

## 5. 구역별 구성

>
> ~~ZONE 1 비위험구역 / ZONE 2 취급구역 / ZONE 3 위험구역~~
> ~~구역마다 가스의 의미가 다르다~~ → **전부 폐기** (정본 §0-5 · `시연장_배치` §2.1).
>
> **왜 뒤집혔나** — 점검점의 내용은 서로 바뀔 수 있다. 캔들이 P1 으로 가면 P1 격리함이 놀고 P4 가 쓰인다.
> 판정에 위치를 넣으면 **소품 하나를 옮기는 순간 코드가 틀린다.**
>
> **그리고 「Zone」이라는 이름 자체가 위험하다** — IEC 60079-10-1 에서 Zone 은 **「그 장소에
> 반입할 수 있는 방폭 기기 등급」**을 정하는 개념이라, 명판에 쓰면 **이 로봇이 인증 기기라고
> 주장**하게 된다. §9.1 이 이미 *"구역 번호를 IEC 순서에 맞추지 않는다"* 로 절반을 막고 있었는데,
> **명칭 자체를 쓰지 않는 것**으로 끝까지 간다.

#### 소구획 사양 — 🔵 관통형 〔2026-08-09 개정〕

> 🔴 **종전은 「라인 옆에 셀을 두고 그리퍼가 개구부로 들어간다」였다.** 개정됐다.
> **라인이 셀을 가로지른다** — 로봇이 개구부로 들어가 안에서 서고, 반대쪽 개구부로 나온다.

```text
   【 셀 하나 · 관통형 】

              ║  주행 라인
       ┌──────╫──────┐
       │      ║      │
       │  ◉   ║      │   ← 물체 + 얕은 링은 라인 옆, 로봇과 같은 공간 안
       │      ║      │
       └──────╫──────┘
              ║
       개구부 = 🔴 차체가 통과하는 너비
```

**무엇이 좋아지나**

| | |
|---|---|
| **「진입」이 동작이 된다** | 지나치는 게 아니라 **구조물 사이로 들어간다.** 순회 점검의 현장감이 는다 |
| 🔵 **P4 대비가 강해진다** | 세 번은 구조물 사이를 지나고 **마지막만 트인 통로**다. 후진도 거기서 일어난다 |
| 🔵 **그리퍼 진입 문제가 사라진다** | 종전엔 그리퍼가 **개구부를 통과해야** 해서 접근면 폭이 실패 지점이었다. 이제 로봇이 이미 안에 있다. 검증이 **「차체가 지나가는가」**로 바뀌어 한 번 주행시켜 보면 끝난다 |
| 제작 부담 | **그대로** — 우드락 6개, 같은 높이 |

> 🔴 **벽을 키우지 말 것. 문제가 되는 건 「관통」이 아니라 「벽이 높아지는 것」이다.**
>
> 배경이 통제되고 현장감이 커 보여서 키우고 싶어진다. 그 순간 넷이 한꺼번에 온다 —
> ① **조명 그림자**(양옆 벽이 물체를 그늘지게 한다. 하필 **NoIR 색 분리가 최대 미해결 항목**이고
> 1순위 대책이 LED 조명이다 — 가장 약한 곳을 때린다) ② **촬영 각도**(파지가 핵심 컷인데
> 상자 안이면 위나 양 끝에서만 찍힌다. **격벽 12면을 폐기하며 없앴던 문제가 되돌아온다**)
> ③ **측면 충돌**(정지 산포 ±30mm 가 팔이 빗나가는 소프트 실패에서 **벽을 들이받는 하드 실패**로 바뀐다)
> ④ **ToF 오검출**.
>
> 🔵 **높이는 확정된 「물체 높이의 1/3~1/2」을 그대로 지킨다.**

| 항목 | 값 | 근거 |
|---|---|---|
| 개수 | **ㄷ자 6개** (P1·P2·P3 × 2) | P4·스테이션은 없음 |
| 🔴 **높이** | **물체 높이의 1/3~1/2** (🔲 실측) — 방지턱 정도 | 🔴 높으면 **팔이 부딪히고 손목 화각을 먹는다.** 배경 통제 욕심으로 키우지 말 것 |
| 개구부 | 🔵 **진입면 + 진출면.** 라인이 둘을 관통한다 | 실제 보관 구획의 접근면은 통로 쪽이다 |
| 🔴 **개구부 폭** | 🔵 **차체 260mm + 정지 산포 ±30 + 여유 → 🟠 400mm 내외** (🔲 실측) | ~~그리퍼 최대 개방 폭~~ — **기준이 그리퍼에서 차체로 바뀌었다** |
| 셀 내경 | 차체 + 팔 동작 여유 + 얕은 링(§7.1.1) | 로봇이 안에 서서 옆의 물체를 잡는다 |
| 🔲 **ToF 장착 높이 ↔ 벽 높이** | **둘 다 미확정.** 🔴 **벽 높이를 먼저 정하고 ToF 를 맞춘다** | 벽 높이는 **촬영·팔·화각**이 정하고 되돌릴 수 없다. ToF 는 높이·임계·**ROI** 세 손잡이가 있다. 🔴 **ToF 가 벽 높이를 정하게 두지 말 것** |
| 🔴 **색** | **무채색 (흰색 또는 회색) · 무광** | 적색·황색 계열 금지. 🔴 **크림·베이지도 금지** — 노란 컵과 Hue 가 겹친다 |
| 재질·고정 | 폼보드·우드락 + **바닥 테이프** | 부딪혀도 물체가 튀지 않게. 🔴 바닥에 **판재를 깔지 않는다** (§10.1) — 세우는 형태만 |
| P1 ↔ P2 | 🔵 **인접한 두 셀** | 같은 제4류라 인접이 자연스럽다 |
| P2 ↔ P3 | 🔵 **떨어뜨린다** | **유별 혼재 제한** — 서사의 핵심 |
| 🔴 **표지** | **부착 금지** | 형태가 설명하게 둔다 (§9.1) |

🔴 **소구획은 손목 카메라의 근경 배경이다.** 물체 바로 뒤라 파지 직전 손목 뷰의 대부분을 차지한다.
→ **데이터 수집 전에 세워야 하고, 고정 조명으로 우회할 수 없다** (`시연장_배치` §7.1).

### 5.1 P1 · P2 — 적색 소분 용기 2개 〔2026-08-09 재편〕

**위치** — 링의 **좌측 구간**, 인접한 두 셀. 🔵 **P1(향 없음)이 P2(향 있음)보다 먼저 온다.**

> 🔴 **이 순서를 뒤집지 말 것.** MQ-2 회복 시간은 약 30초이고 **예열과 무관한 물성**이다.
> 순서가 뒤집히면 잔류 가스로 정상품을 위험물로 오판하고, **데모의 핵심 장면이 그대로 실패 장면이 된다.**

#### 🔵 P1 — 적색 소분 용기 (향 없음) · **통과 판정**

> 🔴 **이 장면이 없으면 이 로봇은 컬러 필터와 구분되지 않는다** 〔2026-08-06 신설〕
>
> 실제 누출 관리 제도는 모든 용기를 뜯지 않고 **임계값으로 정상과 누출을 가른다** —
> LDAR(EPA Method 21)은 임계 미만이면 「누출 아님」으로 통과시키고, 가스누출감지경보기는
> 폭발하한계 25% 이하에서 경보한다.
>
> > **현장에서 비싼 것은 위험을 찾는 능력이 아니라, 정상을 정상이라고 판단하는 능력이다.**
>
> | | 영상에 보이는 것 | 판정 |
> |---|---|---|
> | 음성 사례 없음 | 적색을 보고 집었다 | 🔴 **컬러 필터와 구분 불가** |
> | 🔵 음성 사례 있음 | 적색을 보고 **지나쳤고**, 다른 적색은 집었다 | 🔵 센서 융합으로 **판단**한다 |
>
> **비용은 10초. 파지가 없으므로 실패 리스크가 사실상 0이다.**

- **적색 원통 용기 1개 — 🔵 밀폐 상태로 연출한다.** P2 와 **같은 제품·같은 색**이되 상태가 다르다
- 🔴 **향을 넣지 않는다.** 이 셀 근처에 향 흔적이 남지 않게 관리한다
- 정지점 마커 필요 (정지 → 판정 → 재출발)
- 🔵 **격리함 없음** — 파지하지 않는다
- 얕은 링은 두어도 되고 없어도 된다 (파지하지 않으므로). 🔵 **P2 와 외형을 맞추는 편이 낫다**

#### P2 — 적색 소분 용기 (향 있음) · **파지 → 격리**

- **적색 원통 용기 1개** — 🔴 **뚜껑이 열렸거나 파손된 상태**로 연출한다 (아래 「가스의 원인」)
- 향을 내부에 넣고 개구부로 확산시킨다. 🔴 **향의 양은 최소한으로** — 임계를 넘기기만 하면 된다
- 🔵 **얕은 링 위에 놓는다** — 밀림 방지 (§7.1.1)
- **정지점 마커 2조** (물체 앞 / 격리함 앞) · **격리함 1개**

**공통 연출 요소**

- 출발 위치 표식 · 소형 제어반 모형 · 배관 또는 덕트 모형
- 가스 감지 센서 설치 구역 안내표지 · 센서 수치 표시 출력물
- 라벨은 **자체 제작 표기**를 쓴다 (§9.3)

**제약**

- 제어반과 배관이 라인트레이싱 경로를 침범하지 않아야 한다.
- 센서 모형이 로봇의 카메라나 거리 센서를 가리지 않아야 한다.
- 🔴 **대상은 팔 도달 범위 안, 정지점 마커 기준으로 배치한다.** 위치는 **정지 산포 실측(§13.2) 이후 확정**한다.
  🔵 〔2026-08-09〕 적색이 다시 ACT 로 돌아오면서 이 값의 용도가 또 바뀌었다 —
  **VGR 이 접어주는 범위**와 **ACT 가 학습해야 할 잔여 범위**를 함께 정한다.
- 🔴 **마커 정중앙에 놓지 않는다.** 팔 도달 범위 안에서 **한쪽으로 어긋나게** 둔다 (아래 「방치된 용기」).
- 🔴 **황색 대상이 이 셀들의 촬영 화면에 들어오지 않아야 한다.** 두 대상이 한 화면에 있으면
  손목 카메라 입력이 학습 때와 달라져 ACT 정책이 실패할 수 있다. **소구획과 P2↔P3 이격이 이걸 담당한다.**
- 🔴 **P1 과 P2 가 한 화면에 함께 들어오는 것은 별개 문제다** — 둘 다 적색이라 감지 노드가
  어느 쪽을 대상으로 잡을지 모호해질 수 있다. 🔲 **셀 간격을 실측으로 확보할 것.**

> **🔴 왜 P2 에서 파지하는가 — 「검출 → 조치」로 닫는다**
>
> 가스가 검출됐다면 원인을 제거하는 것이 다음 행동이다. 회수를 붙여야 장면이 닫힌다.

### 5.2 P3 — 노란 종이컵 〔2026-08-09 재편〕

**위치** — 링의 **후면 구간**. 🔴 **적색(P1·P2)과 떨어뜨린다** — **유별 혼재 제한**이 근거다 (§4.2).

**목적**

- **변형 가능 대상**을 학습된 정책으로 회수하는 장면을 보여준다.
- 🔵 **색이 판정 절차 자체를 바꾼다는 것을 증명한다** — 황색은 **가스를 조회조차 하지 않는다.**
  적색만 있으면 판정이 「가스 임계값」 1변수로 붕괴하고, 로봇이 「바퀴 달린 가스 경보기」가 된다.
- 🔵 **단일 정책이 두 물체를 처리한다는 것을 증명한다** — 같은 정책이 손목 픽셀만으로 물체를
  구분해 **Load 임계를 80% → 40% 로 바꾼다.**

#### 🔵 무엇을 대리하는가 — 산화성 고체 〔2026-08-09 확정〕

> 🔴 **종전 근거 — 「반응성·산화성은 존재만으로 위험하다」. 약했다.**
> 산화제가 밀폐된 채 지정 장소에 있으면 위험하지 않다. 그리고 **황색을 왜 치우는지가 화면에 없었다** —
> 적색은 8/04 에 「개방·파손」으로 원인을 넣었는데 황색에는 그 작업을 하지 않았다.

🔵 **인화성 물질 취급구역에 놓인, 산화성 고체를 소분한 개방 용기.**

| 판단 기준 | |
|---|---|
| **형태가 맞는가** | 🔴 **종이컵은 밀폐 용기가 아니다.** 개방·테이퍼·경량. **분말 소분·칭량은 실제로 개방 용기에 한다** |
| **색이 맞는가** | UN Class 5.1 산화성 = 황색 · NFPA 704 황색 = 반응성. **이미 쓰던 근거 그대로** |
| **왜 위험한가 ①** | 🔵 **유별 혼재 제한 위반** — 제1류 산화성 고체는 제4류 인화성 액체와 같은 곳에 둘 수 없다 |
| **왜 위험한가 ②** | 🔵 **용기가 열려 있다** 〔8/9 추가〕 — 개방된 산화제는 비산·오염되고 **인화성 증기가 닿을 수 있다**. 🔴 **②가 없으면 격리함이 원인을 해결하지 않는다** (아래) |
| 🔴 **왜 가스를 안 보나** | 🔵 **고체는 가연성 가스를 내지 않는다. MQ-2 가 볼 것이 물리적으로 없다** |

🔴 **마지막 줄이 이 선택의 핵심이다.** 「가스를 조회하지 않는다」가 **설계자의 선택이 아니라 물리적 사실**이 된다 — *"왜 안 재나요"* → **"잴 게 없습니다."**

🔵 **적색과 위반의 종류가 다르다** — 적색은 *"밀폐돼야 할 것이 열렸다"*, 황색은 *"여기 있으면 안 될 것이 놓였다"*. **그래서 판정 절차도 다르다.**

🔵 **그리고 화재 삼요소가 완성된다** — 적색=가연물 · **황색=산소 공급원** · P4=점화원 (정본 §1).
*"로봇은 치울 수 있는 것을 치우고, 못 치우는 것 앞에서는 물러난다."*

> 🔴 **격리함이 원인을 건드리려면 「개방」이 있어야 한다** 〔2026-08-09 발견〕
>
> 위반을 **「위치」 단독**으로 두면 조치가 원인을 해결하지 않는다. 격리함은 **P3 셀 안**에 있어서
> 로봇이 하는 일은 **산화제를 30cm 옆 상자에 넣는 것**이고, **인화성 취급구역 안이라는 사실은 그대로**다.
> 적색과 비대칭이다 — §5.5 가 든 **「이동 최소화」**가 **황색에는 반대로 작용**한다(오히려 밖으로 빼야 한다).
>

### 5.3 P4 — 캔들 〔2026-08-09 재편〕

### 5.4 충전·대기 스테이션 〔2026-08-04 신설 · 08-04 개정: 루프 밖으로〕

**위치** — **순회 루프 바깥**, 전면 쪽. 지선(스퍼) 하나로 루프와 연결한다.
로봇은 여기서 출발해 지선을 타고 루프에 진입한다.

**왜 루프 밖인가**

- **충전 설비는 점화원**이다. 아크와 열이 나므로 실제 현장에서도 방폭 구역 안에 두지 않는다.
  루프 밖에 두면 **어느 구역에도 속하지 않는 비위험 구역**이 되어 이 규칙을 가장 깨끗하게 만족한다
- 순회 경로 위에 대기 장소가 있으면 **로봇이 자기 차고를 밟고 지나가는** 그림이 된다
- ZONE 3 과 ZONE 1 사이의 이격은 **벽 없는 전면 구간**이 대신 담당한다

**구성**

| 항목 | 값 |
|---|---:|
| 크기 | 620 × 400 (로봇 260 + 여유) |
| 형태 | 낮은 ㄷ자 프레임 + 바닥 표시 |
| 표기 | 「충전·대기 스테이션」 |
| 마커 | **붙이지 않는다** |
| **지선 ↔ 루프 갭** | **120mm** |
| 지선 합류 반경 | ≈ 340mm |

#### 지선은 루프에 연결한다 〔2026-08-04 확정〕

```text
   스테이션 ──╮
              ╰──────╮
   ═════════╫═╫══════╪══════  ← 루프 라인
          정지 감속   합류(접선, R≈340)
```

- **접선 합류.** 직각으로 들이받으면 합류가 불가능하다
- 분기점에 **정지점 마커 2줄**(감속·정지)을 둔다 → 정지점 총 4개, **가로선 8줄**
- 지선은 **양방향** — 나갈 때와 들어올 때 모두 쓴다

#### 🔴 마커만으로는 부족하다 — 분기 선택 로직이 필요하다

**마커 검출과 조향은 다른 회로다.**

| | 조건 |
|---|---|
| 마커 검출 | 5채널이 **전부** 검정 |
| 조향 | 검출된 채널의 **가중평균** |

분기선이 옆에 있으면 5채널을 다 채우지 못해도 **가중평균은 이미 그쪽으로 쏠린다.**
마커를 박아둔다고 이 문제가 사라지지 않는다 — 크로스바를 지난 **직후**부터 분기선이
배열에 들어오면서 로봇이 휜다 (§2 의 「측면 마커는 조향을 깨뜨린다」와 같은 현상).

→ **실제 자기테이프 AGV 가 쓰는 분기 선택 방식을 넣는다.** 두 선이 보이면 전체 평균 대신
**한쪽 연속 그룹만** 본다.

| 상황 | 모드 |
|---|---|
| 순회 중 (분기 무시) | `KEEP_INNER` |
| 스테이션 입고 | `KEEP_OUTER` |

🔲 **신규 튜닝 항목이다.** 라인을 먼저 깔고 **분기 없이** 주행을 안정시킨 다음 분기를 붙인다.
동시에 하면 흔들릴 때 원인이 라인 튜닝인지 분기인지 구분되지 않는다.

#### 정지점 4번은 세되 서지 않는다

**세지 않고 무시하면 안 된다** — 그러면 다음 마커가 몇 번인지 알 수 없다.
카운트는 하고 **액션만 건너뛴다.**

```cpp
stopIndex = (stopIndex % 4) + 1;
if (stopIndex == 4 && !dockRequested) return;   // 세되, 서지 않는다
```

순회 순서는 `ZONE1 → ZONE2 → ZONE3 → 분기점(통과) → ZONE1 …` 이 된다.
RPi 는 순번을 **절대값이 아니라 순환값**으로 받으며, 이제 **4를 법으로** 한다.

상세는 `firmware/구역_마커_설계.md` §6.2.

> **🔴 자동 충전 도킹은 구현하지 않는다**
>
> 3S LiPo 는 **밸런스 충전**이 필요하다. 접점에 전압을 흘려넣는 방식은 셀 불균형을 만들고
> 보호 회로 없이 하면 **화재 위험**이다. 제대로 하려면 BMS 와 CC/CV 충전기가 로봇에 들어간다.
>
> **충전은 배터리를 분리해 수동으로 한다.** 그래도 「충전 위치」라는 이름은 사실이다 —
> 실제로 이 자리에서 충전하기 때문이다.
>
> | 표현 | 판정 |
> |---|---|
> | 충전·대기 스테이션 | ✅ 사실 |
> | 자동 도킹 충전 / 스스로 복귀해 충전 | ❌ 구현하지 않음 |
>
> 발표 답변: *"배터리는 분리해 밸런스 충전합니다. 자동 도킹 충전은 확장 항목입니다."*

**실질 이득 — 연출보다 이쪽이 크다**

- 🔴 **테이크 리셋 지점**. 성공률이 낮아도 되는 대신 재촬영이 많아지는데,
  **매번 같은 자리에서 출발해야** 접근 구간 길이가 같고 정지 산포가 재현된다.
  시작 위치가 흔들리면 산포 실측값도 촬영 결과도 같이 흔들린다
- 순회에 원점이 생긴다. 「계속 도는 구조」는 시작점이 있어야 이야기가 된다
- 오프닝 한 컷 — 스테이션의 로봇에서 시작해 출발
- 배터리 교체·정비를 촬영 중 어디서 할지가 정해진다
- 경계 기둥의 받침을 주행로 안으로 넣지 않는다.
- 우드락 절단면은 부스러지므로 테이프로 감싼다.
- 로봇이 기둥에 부딪히면 기둥이 넘어진다. 파손 문제는 아니지만 재촬영 사유이므로 개구부 여유를 확보한다.

### 5.5 🔴 파지물을 어디로 옮기는가 〔2026-08-04 확정〕

지금까지 「회수 위치로 이동해 내려놓는다」로만 되어 있고 **어디인지가 정해져 있지 않았다.**

#### 실제 현장의 원칙 두 가지

**① 누출 대응의 원칙은 「멀리」가 아니라 「봉쇄」다.**

새는 용기를 들고 이동하면 **경로 전체가 오염된다.** 그래서 현장 절차는 이동을 최소화하고,
그 자리에서 **오버팩 회수 드럼**(손상·누출 용기를 통째로 담는 더 큰 드럼)에 넣어 봉쇄한다.
스필 키트와 방유턱도 같은 목적이다 — 먼저 가두고, 옮기는 것은 그다음이다.

**② 위험물을 일반 구역으로 가져나오지 않는다.**

지정 보관 장소는 **관리되는 구역 안**에 있다. 사무·통행 구역으로 위험물을 옮기는 것은
등급이 낮은 곳을 오염시키는 행위이고, 실제로는 반대 방향이 원칙이다.

#### 🔵 적용 — 점검점마다 격리함 하나 〔2026-08-09 개정〕

> ~~ZONE 1 → 오버팩 회수 드럼 / ZONE 2 → 위험물 보관함, 동작도 서로 다르다~~ → **폐기.**
> 목적지가 **색이 아니라 위치로 결정**되므로 `DESTINATION_BY_CLASS` 매핑 자체가 삭제 대상이 됐다
> (정본 §6.2). 소품도 코드도 함께 단순해진다.

| 점검점 | 파지물 | 목적지 |
|---|---|---|
| **P2** | 적색 원통 (개방·파손) | **P2 격리함** |
| **P3** | 노란 종이컵 | **P3 격리함** |
| P1 · P4 | — | 🔵 **격리함 없음** |

**둘 다 같은 점검점 안에서 끝난다.** 로봇은 **물건을 들고 주행하지 않는다.**

- 적재함이 필요 없다
- 주행 중 낙하로 **테이크가 깨질 위험이 사라진다**
- 촬영 시간이 늘지 않는다

**촬영 편의 때문이 아니라 실제 절차와 일치한 결과다.** 이 점은 발표에서 그대로 말할 수 있다.

#### 격리함 사양 〔2026-08-09 뚜껑 확정으로 개정〕

| 항목 | 값 |
|---|---|
| 개수 | 🔵 **3** — 필요 2개(P2·P3) + **예비 1**. 🔲 세트 제작 부담이 크면 2개로 줄여도 성립 |
| 형태 | 🔵 **흰색 육각 기둥 + 몸통에 경첩으로 붙은 뚜껑** (§5.5.1) |
| 크기 | 🔲 물체 지름 + 여유. 실측 후 |
| 높이 | 🔴 **하한이 생겼다** — ~~낮을수록 좋다~~. **가장 큰 물체가 어떤 자세로 앉아도 뚜껑 아래**여야 한다 (§5.5.1) |
| 고정 | 바닥에 테이프 (투입 충격으로 밀리면 안 됨) |
| 정렬 | 🔵 **정지마커 기준 고정 오프셋.** 🔴 **비전으로 격리함을 찾지 않는다** — 파지 정렬(VGR)이 이미 어려운데 투입 정렬까지 비전에 맡기면 실패 지점이 하나 더 는다 |
| 방향 | 🔴 **평평한 면이 로봇을 향한다.** 꼭짓점이 아니다. 바닥 테이프로 고정 |
| 표기 | 자체 제작 「격리 용기」 |

🔴 **pick 지점과 place 지점이 모두 한 정지점의 팔 도달 범위 안**이어야 한다.
정지 산포 실측 이후에 두 위치를 함께 확정한다 (§13.2).

### 5.5.1 🔵 뚜껑 — 경첩식 · 밀어서 닫는다 〔2026-08-09 신설〕

**격리함은 위가 열린 상자가 아니라 뚜껑이 달린 용기다.** 봉쇄가 화면에서 완결된다.

> 🔴 **얹는 뚜껑은 검토했고 기각했다.**
> 평평한 뚜껑은 손잡이가 없어 평행 그리퍼로 집을 수 없고 — **시연자가 텔레옵으로도 못 하므로
> 데이터 자체가 안 나온다** — 육각 삽입은 힘 피드백 없는 위치 제어에서 mm 단위 정렬을 요구하며,
> 어긋난 채 눌리면 **Load 세이프티 클램프(80%)가 파지 판정용 신호에서 오작동**한다.
> **경첩식은 이 셋을 전부 없앤다.**

#### 동작 — 「닫는다」가 아니라 「넘어뜨린다」

🔴 **닫힌 위치까지 눌러 앉히면 끝점에 하드스톱이 생긴다.** 그러면 과부하 문제가 되돌아온다.

🔵 **수직을 조금 넘어간 각도까지만 밀고 손을 뗀다. 나머지는 중력이 닫는다.**
팔이 닫힌 뚜껑에 닿는 순간이 아예 없다.

```
        열림 (자립)                      닫힘
           ╱                        ┌─────────┐
          ╱  ← 뚜껑                  │  뚜껑    │
    ┌────┘                          ├─────────┤
    │  격리함   │          →          │         │
    │   ▣ 물체  │                     │   ▣     │
    └─────────┘                      └─────────┘
        ▲                                ▲
     로봇 (앞)                         로봇 (앞)

   그리퍼를 닫은 채 위에서 앞으로 쓸어내린다
```

🔴 **경첩은 로봇 반대편 면에 단다.**

| | |
|---|---|
| 열린 뚜껑이 **투입 경로 뒤쪽으로 비킨다** | 물체를 넣을 때 막지 않는다 |
| 릴리스 직후 팔이 이미 격리함 위 높은 곳에 있다 | 밀기가 **그 자세에서 자연스럽게 이어진다** |
| 로봇 쪽 면에 달면 | 🔴 **열린 뚜껑이 투입 경로를 가로막는다.** 쓰지 않는다 |

🔴 **「당기기」는 쓰지 않는다.** 뚜껑 모서리를 걸어야 해서 **파지에 준하는 정밀도**가 다시 필요해진다.
미는 쪽만 쓴다.

#### 🔴 높이 기준이 뒤집혔다

§5.5 는 **「낮을수록 좋다」**로 확정돼 있었다. 근거는 *"들어 올려 넘겨야 하는 높이가 그대로 실패 위험"*.

**뚜껑이 생기면 성립하지 않는다.** 종이컵이 격리함 위로 삐져나온 채 뚜껑이 걸리면
**화면에서 봉쇄가 실패한다.** 파지 실패보다 나쁘다 — 파지는 재시도가 서사에 맞지만
**봉쇄 실패는 결말이 깨진다.**

| | 종전 | 🔵 확정 |
|---|---|---|
| 높이 기준 | 낮을수록 좋다 | 🔴 **가장 큰 물체가 어떤 자세로 앉아도 뚜껑 아래** |
| 예상 하한 | — | 🟠 **내경 130~150mm** (종이컵 90~110mm 급 기준). 🔲 실측 후 확정 |

🟠 **완화책** — 물체가 안에서 눕는 것을 허용하면 **지름 기준**으로 낮출 수 있다.
원통은 잘 눕지만 종이컵은 안 누울 수 있다 → 🔲 **실측 항목** (§13.3).

#### 성립 조건 5개

| # | 조건 | 왜 |
|---|---|---|
| 1 | 🔴 **열림 각도가 매번 같다** — 백스톱 설치 | 접촉 지점이 흔들리면 정책이 못 배운다 |
| 2 | 🔵 **뚜껑 안쪽 면에 대비색** | 아래 설명. **재료비 0원** |
| 3 | 🔴 **격리함 높이 재확정** | 위 항목 |
| 4 | 🔴 **열린 뚜껑이 투입 경로를 막지 않는가** | 「그리퍼 진입 확인」과 같은 성격의 실측 (§13.3) |
| 5 | 🟠 **경첩 내구성 — 수백 사이클** | 🔴 종이테이프 안 됨. **천 테이프 또는 소형 경첩** |

**②가 특히 중요하다.** 손목 카메라 하나로는 **「물체를 놓은 직후 빈 그리퍼」와
「뚜껑을 닫은 직후 빈 그리퍼」가 비슷해 보일 수 있다** — 팔 자세도 비슷하고 그리퍼 상태도 같다.
흰 뚜껑 + 흰 몸통이면 구분 단서가 사실상 없어 **정책이 같은 구간을 반복하거나 건너뛴다.**

🔵 **안쪽 면에 색을 넣으면 열려 있을 땐 색이 보이고 닫히면 사라진다.**
열림/닫힘이 **픽셀 수준에서 자명**해진다. 흰색 대비 문제와 상태 모호성을 **하나로 푼다.**

#### ACT 담당 구간

계획 개선안 v5 §6 프로토콜 ②의 답이 나온다.

| 구간 | 담당 | 근거 |
|---|---|---|
| 접근 · 파지 · 들어올리기 | **ACT** | 물체 위치가 **차체 정지 산포 ±30mm 의 함수**라 변한다 |
| 놓기 · 뚜껑 밀기 | **프리셋** | 격리함이 바닥에 고정 — **변하는 것이 없다** |

🔵 **뚜껑 밀기는 이미 프리셋인 구간(놓기)의 연장선**이다. ACT 구간 사이에 끼지 않으므로
경계 문제가 생기지 않는다.

#### 🔵 데이터 전략 — 수집은 전체, 학습은 나눠서

🟠 **8/21 게이트(물체별 10회 중 8회 파지)** 리스크는 이렇게 없앤다.

**텔레옵으로는 뚜껑 닫기까지 전부 시연해 녹화한다.** 시연자에게도 그게 자연스러운 한 흐름이고
추가 비용은 **에피소드당 3~4초**다.

| | 학습 범위 | 언제 |
|---|---|---|
| **A** | 전체 (파지 → 격리 → 뚜껑) | 먼저 돌린다. 추가 작업 0 |
| **B** | 파지까지만 (잘라서) | A 가 8/21 기준에 못 미치면 |

🔴 **핵심은 순서가 아니라 「지금 안 찍으면 나중에 못 찍는다」는 점이다.**
프론트 카메라에서 배운 것과 같다 — **잘라내는 건 스크립트 작업이지만,
안 찍은 걸 되찾는 건 전량 재수집이다.**

🔵 **그러니 뚜껑 닫기를 학습에 넣을지는 지금 정하지 않아도 된다. 찍어두기만 하면 된다.**

### 6.2 확정 재료와 판재 배분

벽체 재료는 **5T 회색 단프라 900mm × 1800mm**로 확정했으며 주문을 완료했다. 제작 기준 수량은 5장이다.

- 2장: 후면 벽 3600mm × 900mm
- 2장: 좌우 측벽 각 1200mm × 900mm
- 측벽 재단 후 남는 600mm × 900mm 조각 2개: 코너 발과 뒤쪽 버팀대
- 1장: 삼각기둥, 접이식 발, 제어반·배관 소품

### 6.3 폼보드 사용 범위

5T 폼보드는 전체 벽보다 다음 촬영용 디테일에 사용한다.

- 제어반 문과 계기판
- ZONE 1·2·3 명판
- 안전표지 부착판
- 위험물 보관함의 전면
- 배관 지지대와 센서 박스
- 로봇팔 작업대의 외장

5T 폼보드는 0.9m 높이의 실내 촬영 벽 외장으로는 사용할 수 있지만 단독 자립 구조로는 부족하다. 두께를 10T로 올리는 것보다 5T 판의 뒤쪽에 삼각기둥과 접이식 발을 추가하는 편이 경제적이다.

#### 7.1.1 🔵 얕은 링 — 밀림 방지 하나만 한다 〔2026-08-04 신설 · 08-05 축소 · 08-09 근거 정정〕

> 🔴 **2026-08-09 정정 — 「적색 파지의 성립 조건」이라는 위상은 소멸했다.**
> 그 서술은 **적색 = 프리셋**을 전제했는데, 8/6 에 **둘 다 ACT** 로 바뀌었다.
> 링은 이제 성립 조건이 아니라 **소품이자 밀림 방지 장치**다. **황색에도 링을 쓴다** (§5.2).

> 🔴 **링은 정지 산포를 흡수하지 않는다** 〔2026-08-04 정정, 유효〕.
> 링은 **바닥**에 있고 팔은 **차체**에 붙어 있다. 차체가 20mm 덜 서면 용기는 바닥에서
> 안 움직였어도 팔 기준으로는 20mm 어긋난다. 🔵 산포는 **VGR 이 접고, 잔여는 ACT 가** 흡수한다.

**트레이가 실제로 하는 일**

> 🔴 **정정 〔2026-08-05〕 — 아래 근거 두 개는 원기둥 용기에는 성립하지 않는다.**

> | 종전 근거 | 원기둥 드럼통에서는 |
> |---|---|
> | ~~용기를 똑바로 세운다 → 자유도를 x·y 로 줄인다~~ | 🔴 **밑면이 평평한 원기둥은 바닥에서 스스로 똑바로 선다.** 기울 이유가 없다 |
> | ~~높이를 확정한다 (z 를 상수로)~~ | 🔴 **바닥에 놓이므로 z 는 이미 상수다.** 트레이는 오히려 오프셋을 하나 더 얹는다 |

> §7.1.1 은 8/07 신설인데 원통 확정(§5.1)은 8/04 였다. **원통이 된 시점에 이미 약해진 근거가 남아 있었다.**
>
> 🔵 **남는 근거는 하나 — 가벼운 용기의 횡방향 구속.**
> §5.1 이 용기를 *"가볍게. 폼보드·종이 원통"* 으로 규정했다. 가벼운 원통은 밀리고,
> 밀리는 시점이 하필 최악이다 — **접근 중 그리퍼가 스치면, 그리고 파지에 실패하면 거의 반드시 밀린다.**
> 밀리면 다음 테이크의 시작 조건이 달라지고, 손으로 다시 놓으면 위치가 또 달라진다.
> 양면테이프로 용기를 바닥에 붙이는 건 답이 아니다 — **들어올려야 하니까.**
> 필요한 것은 *옆으로는 잡고 위로는 놓아주는* 구속이다.

### 🔵 자기정렬 깔때기 → **얕은 링**으로 축소 〔2026-08-05〕

깔때기(포획 20~30mm)가 흡수하는 것은 **사람이 눈대중으로 놓는 편차**인데, **그건 VGR 이 이미 한다.**
깔때기가 없어도 VGR 이 커버하고, 깔때기가 있어도 차체 산포는 못 막는다. → **자기정렬 기능은 중복이다.**

| | 종전 (깔때기 네스트) | 🔵 개정 (얕은 링) |
|---|---|---|
| 형태 | 원뿔 깔때기 + 원형 구멍 | **테두리 링만** |
| 안지름 | 용기 + 2~4mm | **용기 + 2~4mm** (동일) |
| 높이 | 용기 높이의 1/4~1/3 | **5~10mm** |
| 경사면 | 한쪽 20~30mm | **불필요** |
| 제작 | 반나절~하루 | **1시간** (골판지 2~3겹 · 폼보드 · 3D 프린트) |

- 링 높이가 낮아져 **그리퍼 진입 여유가 오히려 좋아진다** (아래 「벽 높이」 요구의 원래 취지)
- 5~10mm 면 수직으로 걸림 없이 빠진다
- 얕은 사각 팬 위에 링을 얹으면 **누출 방지 받침 외형**은 그대로 유지된다
- 🔴 **링 자체는 바닥에 양면테이프로 고정한다** (링은 안 들어올리므로 문제없다)
- ⚠ 연출 검토 — 팬까지 두면 「제대로 보관돼 있던 것이 파손됐다」로, 링만 두면 「방치」로 읽힌다.

### 8.1 판재 재단

1. 단프라 2장은 1800mm × 900mm 상태로 후면 벽에 사용한다.
2. 단프라 2장은 각각 1200mm × 900mm 측벽과 600mm × 900mm 잔여판으로 재단한다.
3. 마지막 1장은 300mm × 900mm 띠 6개로 재단할 수 있다.
4. 300mm × 900mm 띠는 100mm 간격으로 두 번 접어 삼각기둥으로 만든다.
5. 600mm × 900mm 잔여판은 삼각형 또는 ㄴ자 형태의 접이식 발로 만든다.

단프라는 완전히 자를 선과 한쪽 면만 눌러 접을 선을 구분한다. 접는 선은 단프라 결 방향과 시험 조각의 접힘 상태를 확인한 다음 전체 판에 적용한다.

### 8.2 후면 벽

- 후면 판 2장의 이음부를 정면에서 최소한으로 보이게 맞춘다.
- 뒷면에서 케이블타이와 천테이프로 연결한다.
- 중앙 이음부 뒤에 삼각기둥을 설치한다.
- 판 중앙이 앞뒤로 휘면 각 판의 중앙에도 삼각기둥을 1개씩 추가한다.
- 정면 이음선은 회색 테이프로 직선 처리해 산업용 패널의 이음선처럼 연출할 수 있다.

### 8.3 측벽과 코너

- 후면 벽과 측벽은 90도로 연결해 U자 구조를 만든다.
- 코너는 케이블타이로 먼저 가조립하고 촬영 구도를 확인한 후 테이프로 보강한다.
- 측벽 재단 후 남은 600mm × 900mm 판을 뒤쪽으로 접어 전도 방지 발로 사용한다.
- 받침과 보강재는 카메라에서 보이지 않는 방향으로 배치한다.

### 8.4 산업현장 소품

소품은 모두 가볍고 속이 빈 모형으로 제작한다.

- **제어반:** 회색 단프라 또는 폼보드 상자에 계기판 출력물 부착
- **배관:** 종이관, 얇은 플라스틱관 또는 말아 만든 단프라 사용
- **작업대:** 폐박스 골격을 단프라나 폼보드로 덮어 제작
- **팔레트:** 중성색 골판지를 얇게 적층
- **소분 용기:** 🔵 **3D 프린팅 PLA — 얇은 벽·낮은 채움** 〔8/9 정정 · ~~원통형 종이통 또는 단프라~~〕
- **화재 모형:** 주황·적색 LED와 반투명 종이 사용
- **표지판:** 폼보드 조각에 출력물을 부착해 벽면 위쪽에 설치

소품의 내부에 외부 무게추를 넣지 않는다. 넘어질 우려가 있는 소품은 벽 뒤쪽 구조와 연결하거나 바닥 보호용 마스킹테이프 위에 고정한다.

## 9. 산업현장 연출 기준

### 9.1 적용 원칙

산업안전 관련 법령과 국제표준은 **표지의 의미, 안전한 동선, 로봇 작업구역 관리 개념을 참고하는 근거**로 사용한다. 축소 세트를 해당 기준에 적합한 실제 사업장 시설이라고 주장하지 않는다.

- 「산업안전보건법」 제38조의 기계·설비, 인화성 물질, 에너지 위험에 대한 안전조치 개념을 시나리오에 반영한다.
- 「산업안전보건법 시행규칙」 제38조부터 제40조 및 별표 6~9의 안전보건표지 종류·형태·색채를 표지 디자인에 참고한다.
- 「산업안전보건기준에 관한 규칙」 제22조의 안전한 통로 유지와 통로 표시 개념을 운영자 동선에 반영한다.
- 같은 규칙 제224조의 정비 중 운전 정지와 작업 중 표지 개념을 촬영 중 로봇 정비 절차에 참고한다.
- ISO 7010의 안전표지 체계와 ISO 3691-4:2023의 무인 산업차량 운용구역 안전 개념을 참고한다.
- **KS C IEC 60079-10-1의 폭발성 가스 분위기 장소 구분 개념을 구역 정의와 판정 로직의 근거로 참고한다** (2026-08-03 추가). 구역마다 가스의 의미가 다르다는 설계가 여기서 나온다.

> [!IMPORTANT]
> 구역 정의는 **개념을 참고한 것이며 장소 등급을 주장하는 것이 아니다.**
> 특정 구역을 "Zone 0" 또는 "Zone 1"이라고 표기하거나 설명하지 않는다.
> 구역 번호를 IEC 순서(숫자가 작을수록 위험)에 맞추지 않는다 — 정렬은 곧 등급 주장이다.
> 실제 방폭 표지(Ex 육각형)를 소품으로 부착하지 않는다. 구역 명판은 자체 제작 표기만 사용한다.
> 영상 자막과 나레이션에는 표준 번호를 넣지 않고 개념만 설명한다.

### 9.2 표지와 색상

| 구분 | 세트 적용 |
|---|---|
| 금지 표지 | 출입금지, 화기금지 등 장면에 필요한 최소 수량만 사용 |
| 경고 표지 | 로봇 작동구역, 화재위험, 유해물질 주의 등 |
| 지시 표지 | 보호구 착용 등 산업현장 연출용으로 벽 위쪽에 설치 |
| 안내 표지 | 비상정지, 소화기, 대피 방향 등 |
| 적색·황색 | 처리 대상과 표지에 제한적으로 사용 |
| 검정 라인 | 로봇의 공학적 라인트레이싱 경로로 사용 |

검정 라인은 로봇 센서를 위한 프로젝트 설계 요소이며 법령상 통로 표시 색이라고 설명하지 않는다. 사람 통로와 로봇 라인은 의미를 분리한다.

### 9.3 위험물 표현

- 모형 용기에는 `훈련용 모형`, `위험물 처리 대상 A`, `위험물 처리 대상 B`와 같은 프로젝트용 라벨을 사용한다.
- 실제 화학물질의 명칭과 유해성이 정해지지 않았다면 GHS 그림문자를 붙이지 않는다.
- 적색 강체와 황색 변형체는 HazardBot의 처리 방식 분류라고 설명한다.
- 빈 음료수병이나 생수병을 위험물 용기로 사용하지 않는다.
- 실제 액체 대신 폼, 종이, 빈 플라스틱 모형을 사용한다.

## 10. 로봇·센서·비전 고려사항

### 10.1 라인트레이싱

라인 폭은 임의로 확정하지 않는다. 다음 순서로 결정한다.

1. 현재 AMR에서 안정적으로 사용한 라인의 폭과 재질을 확인한다.
2. 기록이 없다면 15mm, 20mm, 25mm 검정 무광 테이프의 직선 샘플을 시험한다.
3. 강의실의 실제 조명과 바닥에서 센서값을 비교한다.
4. 직선, 완만한 곡선, 이음부를 각각 통과시킨다.
5. 5회 연속 통과한 폭과 재질을 최종 규격으로 고정한다.

바닥에 검정 테이프를 직접 강하게 붙이지 않는다. 먼저 저점착 마스킹테이프를 작은 구역에 붙였다 제거해 잔여물과 바닥 손상을 확인한다.

> [!IMPORTANT]
> **바닥에 판재를 깔지 않는다.** 라인 센서는 바닥과 3~10mm 거리에서만 정상 동작한다.
> 5T 판재를 라인 위나 옆에 깔면 그 구간만 바닥이 5mm 높아져, 7mm로 맞춰둔 센서가 2mm가 되어 포화한다.
> 구역 경계를 포함한 모든 구조물은 **세우는 형태**로만 만든다.

**정지점 마커**

로봇이 정지 지점을 인식하는 방법은 **주행 라인을 가로지르는 검정 가로선**이다. 라인과 같은 테이프를 사용한다.

| 항목 | 기준값 |
|---|---:|
| 폭(진행 방향) | 40mm — 주행 속도 실측 후 재계산 |
| 길이(직각 방향) | 150mm 이상 |
| 각도 | 라인에 직각 |
| 개수 | 정지점당 2개 (감속용·정지용) — 정지점 4곳 = **총 8줄** |
| 감속↔정지 간격 | 200~300mm — 제동거리 실측 후 확정 |

- 정지 마커는 경계 기둥 위치가 아니라 **로봇팔의 기준 자세가 작업물에 도달하는 지점**에 붙인다 (10.3).
- 마커는 로봇용 요소이며 사람을 위한 구역 표시가 아니다. 구역 경계는 기둥과 명판이 담당한다.
- 상세 설계와 검출 조건은 `firmware/구역_마커_설계.md` 참조.

**🔵 정위치 표시를 나란히 둔다** 〔2026-08-04 추가〕

실제 현장의 AGV 정지 마크는 **자기 테이프·RFID 라 사람 눈에 보이지 않는다.**
대신 사람에게 알리기 위해 **바닥에 정위치 표시**를 따로 그린다 — 모서리 ㄱ자 브래킷,
「차량 정지 위치」 표기 같은 것이다.

검정 가로선만 있으면 실험실 감각이 남는다. **정지 마커 옆에 사람용 정위치 표시를 나란히 두면**
검정선이 현장 표기 체계 안으로 들어가고, *"저 검정선은 왜 있나"* 라는 질문에 대한
시각적 답이 화면에 미리 놓인다.

| 항목 | 사양 |
|---|---|
| 형태 | 모서리 ㄱ자 브래킷 4개 또는 좌우 2개 |
| 색 | **흰색 또는 검정** — 🔴 적색·황색 금지 (HSV 충돌, §10.2) |
| 위치 | 로봇이 실제로 멈추는 자리. **정지 산포 실측 이후 확정** |
| 표기 | 자체 제작 「정지 위치」 — 실제 규격 표지를 모사하지 않는다 |
| 비용 | 테이프 잔량으로 처리. 추가 구매 없음 |

🔴 **주행 라인을 가로지르지 않게** 배치한다. 브래킷이 라인에 걸치면 라인 센서가 마커로 읽는다.
차체 폭(260mm) 바깥에 두는 것이 안전하다.

### 10.2 비전 인식

🔵 **로봇의 카메라는 2대다** 〔2026-08-09 정정〕.

| 카메라 | 역할 | 성격 |
|---|---|---|
| **손목 SO-ARM 2MP** (USB) | ACT 입력 전부 | 정색 · 🔴 **단일 장애점** |
| **CSI NoIR V2 8MP** (섀시) | 🔵 **VGR + HSV 물체 검출 + 대시보드 표시** | 🔴 **IR 차단 필터 없음 → 색 왜곡** |

> ## 🔴 감지 카메라가 NoIR 이라는 것이 세트에 주는 요구
>
> IR 차단 필터가 없어 **근적외선이 R 채널로 들어오고, 노랑이 주황·빨강 쪽으로 밀린다.**
> 하필 구분해야 하는 대상이 **적색 vs 황색**이고, **판정표 4행 중 3행이 여기 걸려 있다.**
>
> **세트에서 할 수 있는 대책 (비용 낮은 순)**
>
> | # | 대책 | 세트 항목 |
> |---|---|---|
> | 1 | 🔵 **조명을 LED 로. 백열·할로겐 금지** | **0원 — 조명 선택만.** 🔵 **KY-026 오검출 회피(§5.3)와 방향이 같다** |
> | 2 | 🔵 **AWB·자동노출 고정** — 두 카메라 모두 | 0원 |
> | 3 | 🟠 외장 IR-cut 필터 | 저가 |
> | 4 | 🟠 형상 특징 병용 (면적·채움률·원형도) | 코드 (진우 도메인) |
> | 5 | 🟠 **보유 중인 Innomaker(정색)로 교체** | 0원 — 이미 예비 부품으로 있다 |

- 🔵 **적색·황색 처리 대상 뒤에는 무채색(회색·흰색) 배경을 쓴다** — 소구획이 이 역할을 한다.
  🔴 **크림·베이지 금지** (노란 컵과 Hue 가 겹친다).
- 적색·황색 표지는 물체 인식 카메라의 낮은 시야 영역 밖에 배치한다.
- 반사광이 강하면 조명의 입사각을 바꾸고 무광 출력물로 교체한다.
- 카메라 높이, 각도, 노출, 화이트밸런스를 최종 세트에서 고정한다.
- 처리 대상의 위치와 크기를 고정한 후 HSV 기준과 인식률을 검증한다.
  🔴 **검증은 카메라 2대에서 각각** 한다 — 한쪽이 통과해도 다른 쪽은 별개다.
- 🔴 **소구획을 세운 뒤 조명을 고정하고, 그 상태로 ACT 데이터를 수집한다.**
  소구획은 손목 뷰의 **근경 배경**이라 나중에 세우면 수집분이 어긋나고, **조명으로 우회할 수 없다.**
- 카메라, 로봇팔, 작업대 위치를 변경하면 캘리브레이션과 데이터 재검토 여부를 함께 판단한다.
- 🔴 **VGR 호모그래피는 카메라-팔 베이스 상대 포즈가 고정되어야 성립하고,
  바퀴 교체(카메라~바닥 거리 변화)로 배율이 바뀌면 재측정**해야 한다.

### 10.3 로봇팔과 작업대

- 로봇이 라인을 따라 정지했을 때 로봇팔의 기준 자세가 작업물에 도달해야 한다.
- 작업대 높이는 로봇팔의 실제 작업 가능 영역을 측정한 후 결정한다.
- 작업대는 먼저 폐박스 등으로 임시 제작해 높이를 시험하고, 확정 후 외장재를 붙인다.
- 로봇팔이 최대 범위로 움직여도 벽과 표지판에 닿지 않아야 한다.
- 처리 대상이 떨어져도 라인트레이싱 경로나 바퀴 아래로 굴러가지 않도록 낮은 테두리를 둔다.

### 10.4 구역 경계 통과

로봇 전방에는 VL53L1X 거리 센서가 있고, 장애물을 감지하면 주행 보드가 자체적으로 감속·정지한다. **구역 경계 기둥이 이 센서에 잡히면 경계 앞에서 멈춘다.**

센서 시야각은 27도이므로 측정 폭은 거리의 약 0.48배다.

```text
빔 폭 = 0.48 × 거리

개구부 800mm, 로봇이 중심에 정렬된 경우 기둥까지 각 400mm
기둥이 빔에 들어오기 시작하는 거리 = 400 / 0.24 ≒ 1670mm
로봇이 100mm 치우쳐도 = 300 / 0.24 ≒ 1250mm
```

정지 판단 거리는 1m 이내이므로 **개구부 800mm면 기둥을 장애물로 오인하지 않는다.** 이 값은 4.1의 「라인 중심과 고정 장애물의 이격 400mm 이상」 기준과 일치한다.

- 개구부를 800mm 미만으로 줄여야 하면 **먼저 실제 주행으로 오인 여부를 확인**한다.
- 여유가 부족하면 센서의 측정 영역을 소프트웨어로 좁힐 수 있으나 유효 거리가 함께 줄어든다. 개구부를 넓히는 쪽을 우선한다.
- 경계 기둥 외에 배관·제어반 모형도 같은 기준을 적용한다.

### 10.5 🔴 코너 — ToF 임계 전환 〔2026-08-04 신설〕

**순회 링으로 바뀌면서 코너가 1개에서 4개로 늘었고, 여기서 새 문제가 생긴다.**

코너를 돌 때는 **진행 방향에 반드시 벽이 있다.** 코너 반경이 500mm 이므로
로봇이 코너에 진입하는 순간 정면 벽까지의 거리가 1m 미만이 된다.
현재 정지 판단 거리가 1m 이내이므로 **코너 4개에서 매번 장애물로 읽고 멈춘다.**

이것은 격벽을 세우기 전에도, 링 형태만으로 발생한다.

## 11. 현장 조립 및 철거 순서

### 11.1 조립 전

1. 강의실 담당자에게 사용 구역과 테이프 부착 가능 여부를 확인한다.
2. 바닥을 청소하고 100mm 길이의 테이프로 부착·제거 시험을 한다.
3. 3.6m × 4.0m 외곽과 카메라 위치를 임시 표시한다.
4. 사람 출입구와 피난 동선을 확인한다.
5. 모든 모듈의 날카로운 모서리와 돌출된 케이블타이를 정리한다.

### 11.2 조립

1. 후면 벽 2장을 연결한다.
2. 후면 삼각기둥과 접이식 발을 설치한다.
3. 좌우 측벽을 연결해 U자 구조를 만든다.
4. 벽체의 수직과 흔들림을 확인한다.
5. 저점착 보호층 위에 검정 라인을 설치한다.
6. 제어반, 배관, 작업대, 위험물 모형을 배치한다.
7. 표지판을 벽면 위쪽에 설치한다.
8. LED와 카메라 전원선을 로봇 주행로 밖으로 정리한다.
9. 카메라 구도를 잡고 보강재와 강의실 배경의 노출을 확인한다.
10. 로봇 단독 주행 시험 후 비전·로봇팔 통합 시험을 한다.

### 11.3 철거

1. 로봇과 LED 전원을 끈다.
2. 위험물 모형과 전기 소품을 먼저 제거한다.
3. 라인 테이프와 바닥 보호 테이프를 천천히 제거한다.
4. 측벽, 후면 벽 순서로 해체한다.
5. 케이블타이와 테이프 조각을 회수한다.
6. 판재를 세워서 운반하고 모서리를 보호한다.
7. 강의실 바닥의 잔여물과 손상을 확인한다.

## 12. 시연 안전수칙

### 12.1 운영 원칙

- 전면 개방 상태를 유지한다.
- 관람자는 로봇 주행구역 안으로 들어오지 않게 한다.
- 시연 담당자 한 명을 Emergency Stop과 전원 차단 담당으로 지정한다.
- 로봇이 예상 경로를 벗어나면 즉시 정지한다.
- 센서 오류나 Raspberry Pi 통신 timeout이 발생하면 프로젝트의 안전 fallback 상태를 유지한다.
- 3S LiPo cutoff 기준 `9.9V`와 Emergency Stop 우선순위를 세트 시연을 위해 변경하지 않는다.

### 12.2 벽체와 소품

- 생수병, 금속 추, 벽돌 등 단단한 외부 무게추를 사용하지 않는다.
- 벽체는 정상적인 실내 공기 흐름과 가벼운 케이블 접촉에 넘어지지 않아야 한다.
- 관람자가 기대거나 밀 수 있는 위치에는 벽체를 설치하지 않는다.
- 커터칼과 글루건은 제작 구역에서만 사용하고 시연 중 치운다.
- 판재의 절단면과 케이블타이 끝을 테이프로 감싼다.

### 12.3 화재와 전기

- 🔴 **실화염은 「캔들」에 한해 §5.3 의 조건을 전부 충족할 때만 사용한다** 〔2026-08-09 정합〕.
  ~~실제 화염을 사용하지 않는다~~ → **§5.3 기준으로 통일.** 안전 문서라 어느 절을 보든 같아야 한다.
  🔴 **조건을 못 지키면 촬영하지 않는다.** 유리 홀더 + 금속 트레이 · **가연물 금지 반경 500mm** ·
  경로에서 300mm 이상 · **화재 감시 전담 1명** · 테이크 직전 점화·직후 소화 · 무인 방치 금지
- 발열체, 연막기, 인화성 액체는 **사용하지 않는다.**
- LED는 저발열 제품을 사용한다. 🔵 **백열·할로겐을 쓰지 않는다** — 발열뿐 아니라
  **NoIR 색 밀림과 KY-026 오검출**을 함께 일으킨다 (§10.2)
- 멀티탭과 배터리는 단프라·폼보드 벽 뒤에 밀폐하지 않는다.
- 전원선은 라인트레이싱 경로와 사람 통로를 가로지르지 않게 한다.
- 충전 중인 LiPo 배터리를 세트 내부에 방치하지 않는다.

- [ ] 🔴 **열린 뚜껑이 투입 경로를 막지 않는다** — 파지물을 넣는 팔 동선과 간섭하지 않는다
- [ ] 🔴 **팔이 닫힌 뚜껑을 누르지 않는다** — 수직을 조금 넘긴 지점에서 접촉이 끝난다.
      🔴 **뚜껑 밀기 중 Load 가 클램프 임계에 닿지 않는다** (닿으면 파지 판정 신호가 오염된다)
- [ ] 🔴 **백스톱으로 열림 각도가 매번 같다** — 테이크마다 눈으로 확인
- [ ] 🟠 **경첩이 수백 사이클을 견딘다** — 수집 에피소드 수 + 촬영 테이크 수만큼. 예비 재료를 둔다
- [ ] 🔵 **뚜껑 안쪽 대비색이 손목 카메라에서 확실히 보인다** — 열림/닫힘이 화면에서 구분된다

### 13.4 안전과 철거

- [ ] Emergency Stop과 전원 스위치에 즉시 접근할 수 있다.
- [ ] 관람자 통로와 로봇 주행구역이 겹치지 않는다.
- [ ] 연기·액체 위험물을 사용하지 않는다.

- [ ] 모든 케이블이 로봇과 사람의 이동경로 밖에 있다.
- [ ] 바닥 테이프의 부착·제거 시험에서 손상과 잔여물이 없다.
- [ ] 철거 순서와 판재 보관 위치를 팀원에게 공유했다.
