## 2. 🔴 실배선이 정본과 다른 지점 — MQ 5V

**`배선_확정_2026-08-14.md` §1.1 은 MQ-135/MQ-2 VCC 를 「XL4015 출력에서 별도 한 쌍」으로 못박고 있으나,
실제로는 강희가 ESP_Env 의 5V/VIN 에서 뽑아 쓰고 있다.**

| | 정본 | 실배선 |
|---|---|---|
| MQ VCC 급전 | XL4015 별도 한 쌍 | **ESP_Env 5V/VIN (데이지체인)** |
| 급전점 수 | 6 | **5** |

**영향** — MQ 히터 합산 상시 ~330mA 가 ESP_Env 의 VIN 을 통과한다.

- 🔵 **12V 계통에서는 종전 우려(노트북 USB 폴리퓨즈 500mA)가 적용되지 않는다.** 그 계산은 USB 급전
  시험 조건이었고, 지금은 XL4015 가 급전한다
- 🔴 **남는 문제는 그라운드 바운스다.** 히터 리턴이 ADC GND 와 같은 레일이면 **MQ 를 읽는 그 자리에서**
  기준이 흔들린다 → `GAS_THRESHOLD` 실측을 **이 배선 그대로** 해야 값이 유효하다

## 3. 🔴 통전 전 확인 — 되돌릴 수 없는 것

| # | 확인 | 안 하면 |
|---|---|---|
| ① | 🔴 **XL4016 출력 = 5.0~5.1V, 무부하로 트리밍 후 실측** | **RPi 5 즉사** (₩145,000). RPi 5 는 5.1V 초과를 싫어한다 |
| ② | 🔴 **DFR0753 을 태운 쇼트 지점이 제거됐는지 확인** | **XL4016 도 같은 길을 간다.** 원인 미제거면 부품만 바꾼 것이다 |
| ③ | **트리머는 부하 물리기 전에 돌려놓는다** | 부하를 물린 뒤 조정하면 순간 과전압이 나간다 |
| ④ | 🔴 **ESP_Drive VCC/GND 직납땜** (핀소켓 금지) · GND 핀 2개 이상 | 8/25 보드 사망 재발 — 모터 진동으로 GND 가 빠져 발열 |
| ⑤ | **ESP32 GND ↔ 12V(−) 스타포인트 도통** · 만나는 점은 **한 곳뿐** | 귀환 전류가 로직 경로를 탄다 |
| ⑥ | **배터리 분압 40k/10k = ×5.0 → G39** 멀티미터 보정 | 저전압 정지가 엉뚱한 값에서 걸린다 |
| ⑦ | **라인센서 VCC = 3V3** | ESP32 GPIO 손상 |

### 3.1 XL4016 에 대해 — 보호가 없어졌다

**DFR0753 에 있던 보호(역전압·과전압·과전류·열)가 XL4016 에는 없다.**
`HazardBot_계획변경_및_개선안_v5.md` 가 XL4016 을 기각했던 사유가 그대로 남아 있다:

> 국내 판매글이 「동기식」으로 표기하나 **오표기다.** 외부 쇼트키를 쓰는 **비동기식**이다.

- 🔴 **트리머가 유일한 안전장치다.** 실측 없이 RPi 를 물리지 않는다
- 🔵 용량은 문제없다 — XL4016 은 8A 급, RPi 5 권장 5A(25W)
- 🔵 **시연 전용 우회다.** 촬영이 끝나면 보호 있는 부품으로 되돌리는 것을 전제한다

### 3.2 리더암 — 레일이 없어졌으니 물릴 수 없다

7.4V 레일(XL4015 `#A`)이 삭제됐다. **리더암을 다시 쓸 일이 생기면 12V 를 물리지 말고 XL4015 를
7.4V 로 다시 세운다** — 12V 를 물리면 서보 6개 전멸(₩178,315, **복구 불가**)이다.

## 4. 배터리 — PT-B2200N-SP45

| 항목 | 값 |
|---|---|
| 구성 | 3S1P · 11.1V · 2200mAh · 45C+ |
| 만충 / 스토리지 / 하한 | **12.6V** (4.2V/셀) / 11.4V (3.8V/셀) / 9.0V (3.0V/셀) |
| 충전 | **iMax B6AC** · LiPo BAL-CHG · 3S · **2.2A (1C)** · 밸런스선 필수 |
